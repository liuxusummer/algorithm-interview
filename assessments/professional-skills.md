## 题目 01 Python 列表引用

下面代码输出什么？

```python
matrix = [[0] * 3] * 2
matrix[0][1] = 7
print(matrix)
```

<ol class="assessment-options" type="A">
  <li><code>[[0, 7, 0], [0, 0, 0]]</code></li>
  <li><code>[[0, 7, 0], [0, 7, 0]]</code></li>
  <li><code>[[7, 0, 0], [7, 0, 0]]</code></li>
  <li>抛出异常</li>
</ol>

### 答案

B

### 解析

外层乘法复制了两次对同一个内部列表的引用。修改其中一行，也会从另一行看到同一
对象的变化。独立创建每一行应使用下面的写法。

```python
matrix = [[0] * 3 for _ in range(2)]
```

### 考察点

可变对象、浅复制和引用关系。

## 题目 02 联合索引

订单表的高频查询如下。

```sql
SELECT order_id, create_time
FROM orders
WHERE user_id = ? AND status = ?
ORDER BY create_time DESC
LIMIT 20;
```

以下哪个索引通常最匹配该查询？

<ol class="assessment-options" type="A">
  <li><code>(create_time, user_id)</code></li>
  <li><code>(status, create_time)</code></li>
  <li><code>(user_id, status, create_time)</code></li>
  <li>分别为三个字段建立单列索引</li>
</ol>

### 答案

C

### 解析

查询先对 `user_id` 和 `status` 做等值过滤，再按 `create_time` 排序。联合索引把
等值条件放在前面、排序字段放在后面，可以在定位用户和状态范围后直接按索引顺序
读取前 20 条。真实系统还要结合字段选择性、覆盖列和写入成本验证执行计划。

### 考察点

联合索引顺序、等值过滤、排序和 `LIMIT`。

## 题目 03 并发计数

在不保证“读、加、写”整体原子的运行环境中，多个线程共享整数 `count`，每个线程
执行 `count += 1`。为什么最终结果可能小于预期？

<ol class="assessment-options" type="A">
  <li>整数一定会溢出</li>
  <li>读、加、写组成的复合操作可能交错，产生丢失更新</li>
  <li>操作系统会随机删除变量</li>
  <li>CPU 不支持整数加法</li>
</ol>

### 答案

B

### 解析

两个线程可能先后读到同一个旧值，各自加一后又写回相同的新值，两次操作只产生
一次增长。解决方式取决于语言、解释器和场景，可以使用互斥锁、原子变量，或者让
单一线程汇总消息。必须查看目标运行时的保证，不能仅凭一行代码很短就假定它是
原子操作。

### 考察点

竞态条件、原子性和同步方案。

## 题目 04 SQL 日活跃用户

事件表 `events(user_id, event_time, event_name)` 保存用户行为。请统计
`2026-08-01` 当天发生过至少一次事件的独立用户数。

### 答案

```sql
SELECT COUNT(DISTINCT user_id) AS dau
FROM events
WHERE event_time >= '2026-08-01 00:00:00'
  AND event_time < '2026-08-02 00:00:00';
```

### 解析

`COUNT(DISTINCT user_id)` 去除同一用户的重复事件。时间使用左闭右开区间，能够覆盖
当天全部时间，也避免对时间列套日期函数后影响索引利用。生产环境还要确认业务时区。

### 考察点

去重、时间边界、时区和索引友好的过滤方式。

## 题目 05 A/B 实验判断

实验组购买转化率为 10.4%，对照组为 10.0%。能否仅凭这两个数字宣布实验有效？

<ol class="assessment-options" type="A">
  <li>可以，因为实验组更高</li>
  <li>可以，因为提高了 0.4 个百分点</li>
  <li>不可以，还需要样本量、随机化情况和不确定性分析</li>
  <li>不可以，因为提升不足 1 个百分点</li>
</ol>

### 答案

C

### 解析

同样的 0.4 个百分点，在每组一百人和每组一百万人时证据强度差异很大。还要检查
随机分流、实验周期、样本比例异常、统计区间和多指标选择。D 也不成立，因为业务
价值不能由统一的 1 个百分点阈值决定。

### 考察点

样本量、统计显著性、实验有效性和业务显著性。

## 题目 06 搜索改版指标

产品团队准备改版搜索结果页。请给出一个主要指标、两个保护指标，并说明原因。

### 参考答案

主要指标可以选择搜索成功率，例如用户搜索后在合理时间内点击并完成目标行为的
比例。保护指标可以选择无结果率和搜索后的退出率，也可以根据业务补充延迟、投诉或
长期留存。选择指标时要明确用户目标，避免只追求点击次数，因为增加误导性结果也
可能抬高点击。

### 解析

高质量答案会把用户目标、业务结果和副作用放在一起。指标名称本身不够，需要说明
事件定义、统计窗口和可能被误导的方式。

### 考察点

指标设计、代理指标偏差和保护指标。

## 题目 07 运营项目排序

团队使用 `收益 × 置信度 ÷ 工作量` 作为初步排序分数，三个项目数据如下。

| 项目 | 收益 | 置信度 | 工作量 |
|---|---|---|---|
| A | 8 | 0.8 | 4 |
| B | 6 | 0.9 | 2 |
| C | 9 | 0.5 | 6 |

哪个项目分数最高？

<ol class="assessment-options" type="A">
  <li>A</li>
  <li>B</li>
  <li>C</li>
  <li>三者相同</li>
</ol>

### 答案

B

### 解析

A 的分数为 1.6，B 为 2.7，C 为 0.75。这个公式只能作为初筛。合规要求、任务
依赖、最低服务承诺和战略期限仍可能改变最终顺序。

### 考察点

定量排序、单位一致性和模型边界。

## 题目 08 增量利润

一项活动带来 50 万元新增收入，对应可变成本为 32 万元，活动新增固定成本为
6 万元。忽略税费，活动带来的增量利润是多少？

<ol class="assessment-options" type="A">
  <li>12 万元</li>
  <li>18 万元</li>
  <li>44 万元</li>
  <li>50 万元</li>
</ol>

### 答案

A

### 解析

新增收入减去可变成本得到 18 万元贡献，再减去 6 万元新增固定成本，增量利润为
12 万元。原本就会发生且不受活动影响的固定成本不应重复计入增量判断。

### 考察点

收入、可变成本、增量固定成本和相关成本。
