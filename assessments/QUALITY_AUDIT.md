# 三轮质量审查记录

审查日期为 2026 年 8 月 5 日。审查对象包括章节首页、七个分类页面、导航配置、
内容检查脚本和生产构建结果。这里记录可复核的发现，不记录无法验证的内部推测。

## 第一轮 内容正确性

这一轮把每道练习当成待发布的正式题目，检查题干是否给足条件、答案是否唯一、
计算是否正确，以及解析有没有偷偷使用题目之外的假设。

发现并修正了两处问题。

1. 信息核对题把实际存在差异的第七个字符误写成第六个字符，现已改正。
2. 并发计数题没有明确运行环境是否保证复合操作的原子性，现已补足前提，并在
   解析中要求结合语言、解释器和运行时保证判断。

数字推理和排班推理使用独立脚本复算。专业题中的 SQL 分组口径、实验指标口径、
并发条件和增量收益公式也重新逐项核对。

## 第二轮 作答体验

这一轮从第一次参加校招测评的读者视角检查页面。重点观察答案是否紧跟题目、
错因是否说清楚、不同题型是否误用同一套评分方式。

审查后确认了以下规则。

1. 通用认知和专业能力题给出明确答案、推导过程与易错点。
2. 性格与职业动机题不伪造标准答案，只说明测量维度、作答边界和一致性风险。
3. 情景判断题解释最佳与最差行动，同时说明何时需要升级、留痕和保护用户。
4. AI 视频题只给结构和质量标准，不替读者虚构个人经历。
5. AI 实操题覆盖代码审查、提示词改写、事实核验、仓库修复和敏感信息处理。

首次发布后的页面截图发现，选择题 D 项没有进入列表，导致它与 C 项显示在同一行。
问题来自一次不完整的 Markdown 格式整理。现已将选择题统一为原生 A 至 D 有序列表，
并增加独立的选项样式。

章节检查脚本确认七个分类页面共有 46 组练习，每页均有原创声明、答案区，
并且已经进入侧边栏。页面中的可执行 Python 示例也完成了本地运行验证。

## 第三轮 工程发布

这一轮检查新章节是否能随现有站点正常发布。

1. 顶部导航、侧边栏、项目首页和学习路线均已加入大厂测评入口。
2. 全站内容检查通过，原有面试题、笔试题和专题页没有因本次修改发生回归。
3. VitePress 生产构建成功，七个训练页面和本审查页面均可生成静态页面。
4. 变更范围只包含公开资料链接、原创练习、站点配置和检查脚本，不包含账号、
   令牌、私有仓库地址或候选人个人数据。

构建过程中存在已有的资源块体积提示，不影响静态页面生成。后续若继续扩充章节，
应先补题，再更新计数检查，最后重复以上三轮检查。
