# 大厂测评

投完简历以后收到的链接，可能是通用测评，也可能是专业笔试或 AI 面试。
这几类考察的能力、答题方式和准备方法差异很大。本章先帮你认清类型，再用
46 组原创练习覆盖常见形式。

## 内容边界

本章根据招聘官网和测评厂商公开的题型说明编写。所有练习均由本站重新命题，
用于训练能力，不宣称来自某家公司，也不会复刻受版权或保密约束的正式题目。
公司、岗位和批次会改变测评组合，正式作答仍以邀请邮件为准。

收到测评也不必然表示简历已经通过。德勤目前会在完成网申后自动触发在线测试，
小米把线上测评安排在简历评估之前，华为公开流程则说明简历筛选通过后再安排
综合测评和考试。

## 推荐顺序

第一次参加测评时，先完成通用认知能力的八题，熟悉限时读题和排除选项。
随后阅读性格与职业动机页面，理解问卷在观察什么。情景判断需要单独练习，
因为它考的是工作环境中的判断顺序。专业笔试按目标岗位选做。收到视频或 AI
实操邀请以后，再进入对应页面进行录制和实际操作。若邀请里出现小游戏、工作消息
或虚拟任务，最后练习游戏化测评与任务模拟。

建议每次练习保留三份记录。

1. 写下题目要求的输出，避免答非所问。
2. 写下自己选错的原因，区分知识不足、读题错误和时间不足。
3. 隔一天重做错题，确认能够在没有提示时得到同样结论。

本章在发布前完成了内容正确性、作答体验和工程发布三轮检查。实际发现、修正和
验证结果见[三轮质量审查记录](/assessments/QUALITY_AUDIT)。
