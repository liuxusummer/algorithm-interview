# 03 情景判断

情景判断题会给出一段工作场景，让你选择最有效和最无效的行动，或者为多个行动
排序。SHL公开说明表明，这类测评可以按照岗位和企业文化定制。因此下面答案采用
通用的职业原则，帮助你练习判断过程，不代表任何公司的内部评分标准。

做题时先辨认四件事。当前风险有多大，哪些事实已经确认，谁有决定权，行动是否
可逆。高质量选择通常能控制风险、保留证据、及时沟通并推进下一步。

## 题目 01 线上指标异常

你刚发布一个小流量功能，监控显示错误率开始上升，但暂时没有用户投诉。你会怎样
处理？

<ol class="assessment-options" type="A">
  <li>等收到用户投诉以后再处理，避免误报。</li>
  <li>立即删除全部日志，防止问题继续扩散。</li>
  <li>核对监控和变更范围，通知值班人员，按预案限制影响并保留排查证据。</li>
  <li>把包含用户信息的完整日志发到公开群，请所有人帮忙检查。</li>
</ol>

### 建议判断

最有效的是 C，最无效的是 D。

### 解析

C 同时处理事实核对、影响控制、责任通知和证据保留。A 把监控信号置于用户投诉
之后，可能延误处置。B 会破坏排查证据。D 还增加了数据泄露风险，因此问题最严重。

### 识别信号

看到线上异常，先找可逆的止损动作和正式响应流程。不要为了显得果断而破坏证据，
也不要把敏感数据扩大传播。

## 题目 02 两位负责人意见冲突

产品负责人希望本周上线，技术负责人认为关键依赖尚未验证。两人都让你按自己的
意见执行。

<ol class="assessment-options" type="A">
  <li>私下选择职位更高的一方，不再通知另一方。</li>
  <li>整理两种方案的收益、风险和时间影响，请明确的决策人确认，并同步最终结论。</li>
  <li>同时开发两个完整版本，等上线前再决定。</li>
  <li>在群里指出两位负责人沟通能力差，让他们自行解决。</li>
</ol>

### 建议判断

最有效的是 B，最无效的是 D。

### 解析

B 把分歧转换成可判断的信息，也确认了决定权。A 隐藏分歧，后续责任和目标仍然
不清。C 可能浪费大量工作。D 攻击个人，又没有帮助团队形成决定。

### 识别信号

意见冲突题常考察能否把立场之争改写成目标、证据、代价和决策权问题。

## 题目 03 交付可能延期

距离截止时间还有三天。你发现外部接口的变更会让当前方案至少晚两天完成。

<ol class="assessment-options" type="A">
  <li>暂时不说，希望最后一天能够赶完。</li>
  <li>悄悄删除测试步骤，保证界面按时出现。</li>
  <li>尽早报告新信息，给出缩小范围、增加支持或调整时间三种可行选择。</li>
  <li>连续加班，但不重新估算，也不向团队说明风险。</li>
</ol>

### 建议判断

最有效的是 C，最无效的是 B。

### 解析

C 给团队留下选择时间，并提供具体替代方案。A 和 D 都让风险停留在个人手中。
B 通过隐藏质量变化制造按时完成的假象，可能把延期问题变成线上故障。

### 识别信号

延期本身不一定是最差结果。晚报告、隐藏范围变化和牺牲关键验证通常会放大损失。

## 题目 04 用户数据请求

同事为了赶分析报告，请你把一份包含手机号的原始用户数据上传到个人网盘。他说
只使用一天。

<ol class="assessment-options" type="A">
  <li>同意，因为使用时间很短。</li>
  <li>删除文件名中的“用户数据”后上传。</li>
  <li>拒绝使用个人网盘，确认业务所需字段，通过获批环境提供脱敏后的最小数据集。</li>
  <li>把文件发给更多同事，请大家共同承担决定。</li>
</ol>

### 建议判断

最有效的是 C，最无效的是 B。

### 解析

C 遵守授权渠道、数据最小化和脱敏原则，也没有直接阻断合理业务。A 忽略了渠道
风险。B 只改变文件名，既没有减少敏感信息，也体现出主动规避识别。D 扩大了数据
接触范围。

### 识别信号

安全和隐私题要区分业务目的与处理方式。目的合理也不能自动使任何传输方式合理。

## 题目 05 客户强烈投诉

客户反馈系统重复扣费，情绪激动，要求你立即承诺当天赔偿。你还没有查看订单记录。

<ol class="assessment-options" type="A">
  <li>先承诺全部赔偿，让客户冷静下来。</li>
  <li>说明自己不负责支付系统，要求客户联系别人。</li>
  <li>确认客户诉求和订单标识，说明将立即核查，给出明确反馈时间并同步相关负责人。</li>
  <li>与客户争论系统通常不会出错。</li>
</ol>

### 建议判断

最有效的是 C，最无效的是 D。

### 解析

C 接住客户问题，也没有在事实不清时做超出权限的承诺。A 可能造成错误承诺。
B 只完成责任转移。D 既否定客户体验，也没有获取任何排查信息。

### 识别信号

客户场景先处理情绪和事实，再给可兑现的下一步。不要用未经核查的结论换取短暂安静。

## 题目 06 模糊的新任务

主管让你“尽快做一份竞品分析”，没有说明范围、用途和截止时间。你第一次处理此类
任务。

<ol class="assessment-options" type="A">
  <li>等主管主动补充信息。</li>
  <li>收集能找到的全部资料，写到足够长再提交。</li>
  <li>先确认报告服务的决定、目标对象和时间，提出一页结构与首个检查点。</li>
  <li>复制上一位同事的旧报告，只替换产品名称。</li>
</ol>

### 建议判断

最有效的是 C，最无效的是 D。

### 解析

C 用少量沟通确定输出和边界，并通过早期检查减少返工。A 没有推进。B 可能投入
很多时间却回答错误问题。D 忽略时效和证据，还可能传播旧结论。

### 识别信号

任务模糊时，最有效的行动通常包含澄清目标、提出初版结构和设置早期反馈点。

## 自己检查答案的五个问题

1. 这个选择会立即增加什么风险？
2. 它依据已确认事实，还是依据猜测？
3. 它有没有通知真正负责和有权决定的人？
4. 它能否保留证据，并为下一步留下选择？
5. 如果所有人都采用这种做法，团队还能稳定工作吗？
