## 01 · 好看的二进制字符串

### 题意重述

一个 01 串“好看”，当且仅当所有 `0` 构成一个连续块、所有 `1` 也构成一个连续块。每次可修改一个字符，求变成好看字符串的最少修改次数。

多组数据中所有字符串长度之和不超过 `2×10^5`。

```text
输入
3
5
01010
4
1111
7
1011000

输出
2
0
1
```

### 只有两种目标形态

好看字符串至多切换一次，只可能是：

```text
000...111...
111...000...
```

枚举分界位置 `k`。维护前 `k` 个字符中的 `0/1` 数量，即可常数时间计算两种目标的修改代价。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n = int(input())
    text = input().strip()
    total_zeros = text.count("0")
    total_ones = n - total_zeros

    prefix_zeros = 0
    prefix_ones = 0
    answer = n

    for split in range(n + 1):
        suffix_zeros = total_zeros - prefix_zeros
        suffix_ones = total_ones - prefix_ones

        # 目标 0...01...1：前缀 1 和后缀 0 需要修改。
        cost_zero_one = prefix_ones + suffix_zeros
        # 目标 1...10...0：前缀 0 和后缀 1 需要修改。
        cost_one_zero = prefix_zeros + suffix_ones
        answer = min(answer, cost_zero_one, cost_one_zero)

        if split < n:
            if text[split] == "0":
                prefix_zeros += 1
            else:
                prefix_ones += 1

    print(answer)


T = int(input())
for _ in range(T):
    solve()
```

### 正确性与复杂度

算法枚举了所有可能分界点和两种合法形态。对固定方案，统计值恰好等于所有与目标不同的位置数量，因此取全局最小就是最少修改次数。

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`；
- 分界点包含 `0` 和 `n`，从而覆盖全 `0`、全 `1`。

## 02 · 地图上的最短别墅距离

### 题意重述

`0` 表示别墅，`1` 表示其他位置。输出地图上每个格子到最近别墅的四方向最短距离，`1 <= n,m <= 1000`。

```text
输入
3 4
0111
0011
1111

输出
0 1 2 3
0 0 1 2
1 1 2 3
```

本题和 3.26 场的“该回家了”以及 [LeetCode 542 · 01 矩阵](https://leetcode.cn/problems/01-matrix/) 使用同一模型。

### 多源 BFS

把所有别墅同时设为距离 `0` 并入队，向外逐层扩展。第一次到达每个格子的距离就是它到最近源点的距离。

### Python ACM 实现

```python
import sys
from collections import deque

input = sys.stdin.readline


def solve() -> None:
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    distance = [[-1] * m for _ in range(n)]
    queue = deque()

    for row in range(n):
        for column in range(m):
            if grid[row][column] == "0":
                distance[row][column] = 0
                queue.append((row, column))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while queue:
        row, column = queue.popleft()

        for delta_row, delta_column in directions:
            next_row = row + delta_row
            next_column = column + delta_column

            if (
                0 <= next_row < n
                and 0 <= next_column < m
                and distance[next_row][next_column] == -1
            ):
                distance[next_row][next_column] = distance[row][column] + 1
                queue.append((next_row, next_column))

    for row in distance:
        print(" ".join(map(str, row)))


solve()
```

### 正确性与复杂度

多源 BFS 等价于新增一个连接全部别墅的超级源点。BFS 按路径长度递增访问结点，所以每个格子首次访问时得到全局最短距离。

- 时间复杂度：`O(nm)`；
- 空间复杂度：`O(nm)`；
- 所有源点必须同时入队，不能依次单独搜索。

## 03 · 最大化打铁次数的期望

### 题意重述

共有 `n` 周。参加第 `i` 场比赛可获得 `p[i]` 的期望打铁次数，但有 `q[i]` 的概率被禁止参加下一周；禁令只持续一周。每周可主动参加或跳过，求赛季最大期望。

```text
输入
2
0.5 0.5
0.5 0.0

输出
0.7500000000
```

### DP 定义与转移

设 `f[i]` 表示从第 `i` 周开始、当前没有被禁赛时的最大期望。两种选择：

```text
skip = f[i+1]
take = p[i] + (1-q[i]) × f[i+1] + q[i] × f[i+2]
f[i] = max(skip, take)
```

参加后若被禁赛，就直接来到 `i+2`；否则正常进入 `i+1`。转移只依赖后两项，可以滚动优化。

### 正确性证明

在第 `i` 周未被禁赛时，合法决策只有参加或跳过。两条转移分别计算这两个决策的完整期望，并在后续使用已经最优的 `f[i+1]、f[i+2]`。根据最优子结构，取两者最大值即为当前最优；倒序归纳得到 `f[0]` 为全局最优。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n = int(input())
    success_probability = [0.0] * n
    ban_probability = [0.0] * n

    for index in range(n):
        success_probability[index], ban_probability[index] = map(
            float,
            input().split(),
        )

    next_week = 0.0
    week_after_next = 0.0

    for index in range(n - 1, -1, -1):
        skip = next_week
        take = (
            success_probability[index]
            + (1.0 - ban_probability[index]) * next_week
            + ban_probability[index] * week_after_next
        )
        current = max(skip, take)

        week_after_next = next_week
        next_week = current

    print(f"{next_week:.10f}")


solve()
```

### 复杂度与易错点

- 时间复杂度：`O(n)`；
- DP 额外空间复杂度：`O(1)`，输入数组占 `O(n)`；
- `p[i]` 与 `q[i]` 是两个不同概率，不能相乘作为本场收益；
- 被禁赛时跳过恰好一周，所以转移到 `f[i+2]`。
