## 01 · 拼好房

### 题意重述

房子下方是长方形，上方是等腰三角形，二者共用长方形上边。每根木棍最多使用一次，判断给定木棍能否拼出房子。

```text
输入
6
4 4 3 3 5 5

输出
YES
```

### 只需要三对等长木棍

房子需要：

- 长方形上下边一对；
- 长方形左右边一对；
- 三角形两条腰一对。

只要有三对等长木棍，就把三对长度从小到大记为 `a <= b <= c`，取 `a` 为三角形底边、`b` 为两腰。因为长度为正且 `b >= a`，所以 `2b > a`，三角形一定合法。

### Python ACM 实现

```python
import sys
from collections import Counter

input = sys.stdin.readline


n = int(input())
lengths = list(map(int, input().split()))
frequency = Counter(lengths)
pair_count = sum(count // 2 for count in frequency.values())

print("YES" if pair_count >= 3 else "NO")
```

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`；
- 某种长度出现四次，可以提供两对木棍。

## 02 · 不降序序列

### 题意重述

给定 `n` 个整数序列，统计有序对 `(i,j)` 的数量，允许 `i=j`，要求拼接 `Sᵢ + Sⱼ` 后整体不降序。

```text
输入
2
3
2 1 3
3 2 4 6
2 5 7
2
1 5
1 3

输出
1
3
```

### 三个必要且充分条件

拼接后不降序，当且仅当：

1. `Sᵢ` 自身不降序；
2. `Sⱼ` 自身不降序；
3. `last(Sᵢ) <= first(Sⱼ)`。

先过滤所有非法序列。把合法序列的首元素排序，对于每个末元素 `last`，用 `bisect_left` 找到第一个不小于它的首元素，其右侧全部可以作为第二个序列。

### Python ACM 实现

```python
import sys
from bisect import bisect_left

input = sys.stdin.readline


def solve() -> None:
    n = int(input())
    first_values = []
    last_values = []

    for _ in range(n):
        row = list(map(int, input().split()))
        length = row[0]
        sequence = row[1:]

        is_non_decreasing = all(
            sequence[index - 1] <= sequence[index]
            for index in range(1, length)
        )

        if is_non_decreasing:
            first_values.append(sequence[0])
            last_values.append(sequence[-1])

    first_values.sort()
    answer = 0

    for last in last_values:
        first_valid = bisect_left(first_values, last)
        answer += len(first_values) - first_valid

    print(answer)


T = int(input())
for _ in range(T):
    solve()
```

### 正确性与复杂度

过滤后，序列内部已经满足要求，拼接处是唯一可能下降的位置。二分统计的正是首元素不小于当前末元素的全部候选，因此每个合法有序对被计算一次。

- 时间复杂度：`O(L + n log n)`，`L` 为所有序列总长度；
- 空间复杂度：`O(n)`；
- 题目统计有序对，不能除以二；
- 输入的每行首个数字是序列长度，不属于序列内容。

## 03 · 二次幂变换 2

### 题意重述

每次操作可以选择 `x` 或 `y` 中的一个数，加上任意 `2^k`。求让两数相等的最少操作次数。

```text
输入
5
0 0
7 0
5 14
-3 5
3 10

输出
0
2
2
1
2
```

### 转化为最小有符号二进制权重

只需考虑差值 `d = |x-y|`。一次给较小值加 `2^k` 相当于从差中减去该幂；给较大值加则相当于向差中加该幂。因此要用最少个带正负号的二次幂表示 `d`。

普通二进制中一串连续的 `1` 可以改写：

```text
00111100 = 01000000 - 00000100
```

连续多个 `1` 从多次操作降为两次。最低位遇到 `...11` 时执行 `d += 1` 触发进位；遇到孤立 `1` 时直接消去该位。这正是非相邻形式（NAF）的贪心构造。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def minimum_operations(difference: int) -> int:
    difference = abs(difference)
    operations = 0

    while difference > 0:
        if difference & 1:
            operations += 1
            if difference & 3 == 3:
                # 连续 1：使用 -2^k，并向高位进 1。
                difference += 1
            else:
                # 孤立 1：直接使用 +2^k 消掉当前位。
                difference -= 1

        difference >>= 1

    return operations


T = int(input())
for _ in range(T):
    x, y = map(int, input().split())
    print(minimum_operations(y - x))
```

### 正确性与复杂度

最低位为偶数时无需操作，直接除以二。最低位为孤立 `1` 时消去它最优；若最低两位都是 `1`，向上进位会一次合并整段连续 `1`，不可能比逐个消除更差。该规则生成的 NAF 没有相邻非零位，而 NAF 的非零位数量最少，因此操作数最小。

- 时间复杂度：`O(log |x-y|)`；
- 空间复杂度：`O(1)`；
- `x、y` 可以为负数，但只需处理绝对差。
