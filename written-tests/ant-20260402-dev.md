## 01 · 也许互质序列

### 题意重述

给定长度为 `n` 的数组 `a` 和正整数 `k`，判断是否同时满足：

1. 每对相邻元素互质；
2. 每对下标相差 `k` 的元素不互质；
3. 所有元素互不相同。

```text
输入
3
5 2
10 21 22 39 34
4 3
10 21 22 25
5 2
2 3 5 7 11

输出
Yes
Yes
No
```

### 解法与证明

三个条件相互独立，逐项验证即可。`gcd` 检查直接对应前两个定义，集合大小对应第三个定义。任一检查失败就返回 `No`；三项全部通过时，数组恰好满足题目定义。

### Python ACM 实现

```python
import sys
from math import gcd

input = sys.stdin.readline


def solve() -> None:
    n, k = map(int, input().split())
    values = list(map(int, input().split()))

    for index in range(n - 1):
        if gcd(values[index], values[index + 1]) != 1:
            print("No")
            return

    for index in range(n - k):
        if gcd(values[index], values[index + k]) == 1:
            print("No")
            return

    if len(set(values)) != n:
        print("No")
        return

    print("Yes")


T = int(input())
for _ in range(T):
    solve()
```

- 时间复杂度：`O(n log V)`；
- 空间复杂度：`O(n)`；
- 第二个循环的上界是 `n-k`，不要访问越界。

## 02 · 按位与权值和

### 题意重述

选择分割点 `p`，把数组分成非空前缀 `B` 和非空后缀 `C`。定义：

```text
S(p) = Σ (B[i] & C[j])
```

求所有合法分割点中的最大 `S(p)`。

```text
输入
1
4
5 2 7 1

输出
8
```

### 按位拆开二重求和

对于第 `bit` 位，只有左右两边对应位都为 `1` 的数对才贡献 `2^bit`。若左侧有 `left_ones` 个、右侧有 `right_ones` 个，则该位贡献是：

```text
left_ones × right_ones × 2^bit
```

先统计全数组各位 `1` 的数量，移动分割点时把新进入左侧的元素更新到前缀计数，即可在固定常数位数内算出当前答案。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline

BITS = 27


def solve() -> None:
    n = int(input())
    values = list(map(int, input().split()))
    total_ones = [0] * BITS

    for value in values:
        for bit in range(BITS):
            total_ones[bit] += (value >> bit) & 1

    prefix_ones = [0] * BITS
    answer = 0

    for split in range(1, n):
        value = values[split - 1]
        for bit in range(BITS):
            prefix_ones[bit] += (value >> bit) & 1

        current = 0
        for bit in range(BITS):
            right_ones = total_ones[bit] - prefix_ones[bit]
            current += prefix_ones[bit] * right_ones * (1 << bit)

        answer = max(answer, current)

    print(answer)


T = int(input())
for _ in range(T):
    solve()
```

### 正确性与复杂度

按位与的每一位互不影响，所有数对在所有位上的贡献被恰好计算一次。每个分割点使用准确的左右 `1` 数量，因此 `current` 等于该分割点的定义值，取最大即为答案。

- 时间复杂度：`O(nB)`，这里 `B=27`；
- 空间复杂度：`O(B)`；
- 分割点范围是 `1..n-1`，左右两段都必须非空。

## 03 · 平方串

### 题意重述

可以在字符串 `s` 的开头和结尾添加任意字符，希望最终字符串形如 `t+t`。求最少添加字符数。

```text
输入
5
abab
abc
aaaea
abe
abca

输出
0
3
3
3
2
```

### 转化为受限 border

设原串长度为 `L`、目标每一半长度为 `k`。目标总长是 `2k`，新增字符数为 `2k-L`。

原串中同时被目标两半覆盖的部分必须相等，等价于：

```text
s 的长度 L-k 前缀 == 长度 L-k 后缀
```

令 `border = L-k`，为了最小化新增数 `L-2×border`，应找不超过 `L/2` 的最长 border。KMP 前缀函数能列出字符串所有 border，避免哈希碰撞。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def minimum_added_characters(text: str) -> int:
    length = len(text)
    prefix = [0] * length

    for index in range(1, length):
        matched = prefix[index - 1]
        while matched > 0 and text[index] != text[matched]:
            matched = prefix[matched - 1]
        if text[index] == text[matched]:
            matched += 1
        prefix[index] = matched

    border = prefix[-1] if length else 0
    # KMP 的 border 链从长到短跳转，直到满足两半不会重叠。
    while border * 2 > length:
        border = prefix[border - 1]

    return length - 2 * border


T = int(input())
for _ in range(T):
    s = input().strip()
    print(minimum_added_characters(s))
```

### 正确性与复杂度

KMP 的 `prefix[-1]` 是最长真前后缀；不断跳到 `prefix[border-1]` 会按长度递减枚举全部 border。第一个满足 `2×border <= L` 的就是允许的最长重合部分，因此新增字符数最小。

- 时间复杂度：`O(L)`；
- 空间复杂度：`O(L)`；
- 目标长度必须是偶数，公式 `L-2×border` 已包含这个约束。
