## 01 · 巴巴博弈

### 题意重述

有 `n` 份礼物，第 `i` 份价值为 `a[i]`。对手先拿走 `k` 份，随后你从剩余礼物中选择不超过 `m` 份，希望总价值至少为 `y`。求能保证达标的最小 `m`；不存在则输出 `-1`。

```text
输入
2
5 2 10
1 2 3 4 5
4 1 7
5 2 4 3

输出
-1
2
```

### 最坏情况分析

为了让剩余礼物尽可能差，对手应拿走价值最大的 `k` 份。排序后，剩余部分已经按价值从大到小排列；为了用最少份数达到 `y`，继续从剩余最大值开始累加。

交换论证：若对手拿走了较小值却留下较大值，交换两者不会让你更难达标，所以最坏方案必可调整为拿走前 `k` 大。你的选择同理，固定份数时取最大的若干份总和最大。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n, k, target = map(int, input().split())
    values = list(map(int, input().split()))
    values.sort(reverse=True)

    current_sum = 0
    for index in range(k, n):
        current_sum += values[index]
        if current_sum >= target:
            print(index - k + 1)
            return

    print(-1)


T = int(input())
for _ in range(T):
    solve()
```

### 复杂度与易错点

- 时间复杂度：`O(n log n)`；
- 空间复杂度：`O(n)`（Python 排序产生的辅助开销视实现而定）；
- 先跳过排序后的前 `k` 个元素；
- 即使剩余所有礼物之和不足，也必须输出 `-1`。

## 02 · 质数合数

### 题意重述

数组中的每个元素都是质数。统计有序下标对 `(i, j)` 的数量，要求 `i != j` 且 `a[i] + a[j]` 是合数。

```text
输入
5
2 2 3 3 2

输出
8
```

### 正难则反

先计算全部有序对 `n(n-1)`，再减去“和仍为质数”的有序对。

质数中只有 `2` 是偶数：

- 两个奇质数之和是大于 `2` 的偶数，一定是合数；
- `2 + 2 = 4`，也是合数；
- 只有 `2 + p` 可能为奇质数，需要检查 `p + 2` 是否为质数。

设 `count_two` 为值 `2` 的个数，`count_twin` 为数组中满足 `p` 为奇质数且 `p+2` 仍为质数的元素个数。需要减去的有序对为 `2 × count_two × count_twin`。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def build_sieve(limit: int) -> list[bool]:
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    number = 2
    while number * number <= limit:
        if is_prime[number]:
            for multiple in range(number * number, limit + 1, number):
                is_prime[multiple] = False
        number += 1

    return is_prime


n = int(input())
values = list(map(int, input().split()))
is_prime = build_sieve(max(values) + 2)

count_two = 0
count_twin = 0

for value in values:
    if value == 2:
        count_two += 1
    elif is_prime[value + 2]:
        count_twin += 1

prime_sum_pairs = 2 * count_two * count_twin
print(n * (n - 1) - prime_sum_pairs)
```

### 正确性与复杂度

上述分类覆盖了所有质数对，且三类互不重叠；前两类必为合数，第三类通过筛表精确判断。因此总有序对减去第三类中的质数和对，恰为答案。

- 时间复杂度：`O(V log log V + n)`；
- 空间复杂度：`O(V)`；
- 统计的是有序对，所以 `(2,p)` 与 `(p,2)` 都要计算。

## 03 · 位运算权值

### 题意重述

给定数组 `a`、操作串 `s` 和上界 `r`。`s[i]` 为：

- `1`：计算 `a[i] AND x`；
- `2`：计算 `a[i] XOR x`；
- `3`：计算 `a[i] OR x`。

从 `[1, r]` 中选整数 `x`，最大化所有运算结果之和。

```text
输入
3
3 7
1 2 3
123
4 3
1 1 1 1
1111
5 10
5 6 7 8 9
23231

输出
15
4
60
```

### 按位贡献

对每一位 `bit`，预处理：

- `gain_zero[bit]`：`x` 该位取 `0` 时，所有表达式在该位的总贡献；
- `gain_one[bit]`：`x` 该位取 `1` 时的总贡献。

若没有 `x <= r` 的限制，每一位独立选贡献较大的即可。加入上界后，使用从高位到低位的数位 DP：

```text
状态 = (是否仍与 r 前缀相等, 是否已经出现过 1)
```

第二维用于排除 `x = 0`。

### 正确性证明

位运算不会跨位产生进位，所以一个 `x` 的总价值等于各位贡献之和。数位 DP 枚举了所有不超过 `r` 的二进制前缀，并为每个等价状态保留最大价值；相同状态的未来可选集合完全一致，舍弃较小价值不会影响最优解。最终只取非零状态，得到 `[1,r]` 中的最大值。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n, upper_bound = map(int, input().split())
    values = list(map(int, input().split()))
    operations = input().strip()
    # 即使 x <= r，a[i] 的更高位仍可能通过 XOR / OR 贡献答案。
    bit_count = max(1, upper_bound, max(values)).bit_length()

    gain_zero = [0] * bit_count
    gain_one = [0] * bit_count

    for value, operation in zip(values, operations):
        for bit in range(bit_count):
            value_bit = (value >> bit) & 1
            weight = 1 << bit

            if operation == "1":  # AND
                gain_one[bit] += value_bit * weight
            elif operation == "2":  # XOR
                gain_zero[bit] += value_bit * weight
                gain_one[bit] += (1 - value_bit) * weight
            else:  # OR
                gain_zero[bit] += value_bit * weight
                gain_one[bit] += weight

    # (tight, non_zero) -> 当前前缀能获得的最大贡献
    dp = {(1, 0): 0}

    for bit in range(bit_count - 1, -1, -1):
        limit_bit = (upper_bound >> bit) & 1
        next_dp = {}

        for (tight, non_zero), score in dp.items():
            maximum_bit = limit_bit if tight else 1

            for chosen_bit in range(maximum_bit + 1):
                next_tight = int(tight and chosen_bit == limit_bit)
                next_non_zero = int(non_zero or chosen_bit == 1)
                gain = gain_one[bit] if chosen_bit else gain_zero[bit]
                state = (next_tight, next_non_zero)
                next_dp[state] = max(next_dp.get(state, -1), score + gain)

        dp = next_dp

    print(max(score for (tight, non_zero), score in dp.items() if non_zero))


T = int(input())
for _ in range(T):
    solve()
```

### 复杂度与易错点

- 时间复杂度：`O(nB)`，`B = bit_length(max(r, max(a)))`；
- 空间复杂度：`O(B)` 保存按位贡献，DP 状态只有常数个；
- 不要把三种操作的 `0/1` 贡献写反；
- `x` 的下界是 `1`，必须排除全零方案。
