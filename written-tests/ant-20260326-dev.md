## 01 · 排列拼接 {#problem-01}

### 题意重述

给定两个长度为 `n` 的排列 `a`、`b`。把 `a` 连续复制 `k` 次，要求 `b` 能作为拼接数组的子序列出现，求最小的 `k`。

输入第一行是测试组数 `T`。每组依次输入 `n`、排列 `a`、排列 `b`。

```text
输入
1
5
2 3 1 5 4
3 5 4 2 1

输出
2
```

### 建模与关键观察

`a` 是排列，所以每个值在一份 `a` 中只出现一次。记录 `pos[x]` 表示值 `x` 在 `a` 中的位置。

顺序处理 `b`：

- 若当前值的位置大于上一个值的位置，二者可以放在同一份 `a` 中；
- 否则当前这份 `a` 已经越过该位置，必须进入下一份复制。

因此，答案就是位置序列 `pos[b[0]], pos[b[1]], ...` 中“非严格上升断点”的数量加一。

### 正确性证明

贪心始终把当前元素放进最早可用的那份 `a`。若 `pos[b[i]] > pos[b[i-1]]`，继续使用当前副本不会影响后续选择；若不满足，则任何保持子序列顺序的方案都不能把二者放在同一副本中，新增副本是必要的。每次新增都不可避免，因此得到的副本数最小。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    position = [0] * (n + 1)
    for index, value in enumerate(a):
        position[value] = index

    copies = 1
    previous_position = -1

    for value in b:
        current_position = position[value]
        # 位置没有继续向右，说明必须进入下一份 a。
        if current_position <= previous_position:
            copies += 1
        previous_position = current_position

    print(copies)


T = int(input())
for _ in range(T):
    solve()
```

### 复杂度与易错点

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(n)`；
- 判断条件必须是 `<=`，因为同一个位置不能在子序列中使用两次；
- `copies` 初始值为 `1`，空副本不计入答案。

## 02 · 该回家了 {#problem-02}

### 题意重述

给定一个 `n × m` 的 01 网格，对每个格子输出它到最近 `0` 格子的曼哈顿距离。只能向上下左右移动。

```text
输入
3 4
0111
0011
1111

输出
0 1 2 3
0 0 1 2
1 1 2 3
```

这与 [LeetCode 542 · 01 矩阵](https://leetcode.cn/problems/01-matrix/) 是同一模型。

### 为什么要反向搜索

从每个 `1` 分别 BFS 会重复遍历网格。更好的方式是把所有 `0` 同时放进队列，相当于建立一个连接所有 `0` 的超级源点，再做一次 BFS。

BFS 按距离从小到大扩展，所以一个格子第一次被访问时，得到的必然是到任意 `0` 的最短距离。

### 正确性证明

初始队列中的所有 `0` 距离均为 `0`。假设队头格子距离为 `d`，它扩展出的未访问邻居存在一条长度为 `d+1` 的路径。由于队列中所有更短距离的格子都已经处理完，不可能存在更短路径尚未发现，因此第一次写入的 `d+1` 就是最短距离。归纳可知所有格子的结果正确。

### Python ACM 实现

```python
import sys
from collections import deque

input = sys.stdin.readline


def solve() -> None:
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    distance = [[-1] * m for _ in range(n)]
    queue = deque()

    for row in range(n):
        for column in range(m):
            if grid[row][column] == "0":
                distance[row][column] = 0
                queue.append((row, column))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while queue:
        row, column = queue.popleft()
        for delta_row, delta_column in directions:
            next_row = row + delta_row
            next_column = column + delta_column

            if (
                0 <= next_row < n
                and 0 <= next_column < m
                and distance[next_row][next_column] == -1
            ):
                # 第一次到达即为离所有源点最近的距离。
                distance[next_row][next_column] = distance[row][column] + 1
                queue.append((next_row, next_column))

    for row in distance:
        print(" ".join(map(str, row)))


solve()
```

### 复杂度与易错点

- 时间复杂度：`O(nm)`；
- 空间复杂度：`O(nm)`；
- 所有 `0` 必须在 BFS 开始前一次性入队；
- 使用 `-1` 同时表示“未访问”，避免额外的访问数组。

## 03 · 破译者 {#problem-03}

### 题意重述

对每组非负整数 `a, b, c`，选择非负整数 `x`：

- `c > 0` 时满足 `x ≡ b (mod c)`；
- `c = 0` 时规定 `x = b`。

最小化 `a XOR x`，输出最小值。

```text
输入
2
10 10 3
21 13 5

输出
0
2
```

### 高位优先与可行区间

异或值的高位权重大于所有低位之和，因此从最高位开始，优先让 `x` 的当前位等于 `a`。

固定到第 `bit` 位后，剩余低位任意取值，所有候选 `x` 构成连续区间 `[low, high]`。要判断其中是否存在余数为 `r = b % c` 的数，只需求不小于 `low` 的第一个同余数：

```text
first = low + (r - low) mod c
```

若 `first <= high`，当前位可以与 `a` 保持一致；否则只能翻转。

### 正确性证明

每一步把当前可行集合按当前位分成两个区间。若与 `a` 相同的分支仍含合法解，选择它会让当前异或位为 `0`，显然优于另一分支的 `1`；若该分支无解，则翻转是唯一可行选择。由于更高位的贡献严格大于所有低位贡献之和，逐位最优等价于全局最优。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    a, b, c = map(int, input().split())

    if c == 0:
        print(a ^ b)
        return

    remainder = b % c
    # 多留一位，保证完整搜索区间一定包含 remainder。
    bit_count = max(a, b, c, 1).bit_length() + 1
    prefix = 0

    for bit in range(bit_count - 1, -1, -1):
        preferred_bit = (a >> bit) & 1
        preferred_prefix = prefix | (preferred_bit << bit)

        low = preferred_prefix
        high = preferred_prefix + (1 << bit) - 1
        first = low + (remainder - low) % c

        if first <= high:
            # 低位仍能补出合法同余数，保留异或为 0 的选择。
            prefix = preferred_prefix
        else:
            prefix |= (1 - preferred_bit) << bit

    print(a ^ prefix)


T = int(input())
for _ in range(T):
    solve()
```

### 复杂度与易错点

- 时间复杂度：`O(log V)`，`V = max(a,b,c)`；
- 空间复杂度：`O(1)`；
- `c = 0` 不能参与取模，必须单独处理；
- Python 的 `%` 已返回非负余数，因此 `(remainder - low) % c` 可直接使用。
