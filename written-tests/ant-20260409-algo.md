## 01 · 穿过黑暗之门

### 题意重述

初始权值为 `1`。共有 `n` 关，每关可从两种运算中选择一种，运算符为 `+、-、*、/`，除法向下取整。每次运算后把权值截断在 `[1, 10^9]`，求最终最大权值。

```text
输入
3
+ 10 * 2
* 2 / 5
- 5 / 2

输出
17
```

### 单调性就是贪心依据

四种运算的参数均为正数。对任意 `x <= y`，分别执行同一种运算并截断后，结果仍满足 `f(x) <= f(y)`。因此当前值越大，未来经过任意相同选择序列后的结果也不会更小。

每一关直接选当前结果较大的门，局部最优不会损害未来，归纳可得最终全局最优。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline

LOWER = 1
UPPER = 10**9


def apply_operation(value: int, operator: str, operand: int) -> int:
    if operator == "+":
        value += operand
    elif operator == "-":
        value -= operand
    elif operator == "*":
        value *= operand
    else:
        value //= operand

    return max(LOWER, min(value, UPPER))


n = int(input())
current = 1

for _ in range(n):
    operator_one, value_one, operator_two, value_two = input().split()
    result_one = apply_operation(current, operator_one, int(value_one))
    result_two = apply_operation(current, operator_two, int(value_two))
    current = max(result_one, result_two)

print(current)
```

- 时间复杂度：`O(n)`；
- 空间复杂度：`O(1)`；
- 截断发生在每一关之后，不能只在最后处理。

## 02 · 离散型马尔可夫模型预测

### 题意重述

仅使用 NumPy 实现 HMM 的 Viterbi 解码。输入单行 JSON，包含：

- `pi`：初始状态概率；
- `A`：状态转移矩阵；
- `B`：观测发射概率矩阵；
- `obs`：多条离散观测序列。

为每条观测序列输出最可能的隐藏状态路径和对应对数概率，保留六位小数。

```text
输入
{"pi":[0.6,0.4],"A":[[0.7,0.3],[0.4,0.6]],"B":[[0.5,0.4,0.1],[0.1,0.3,0.6]],"obs":[[0,0]]}

输出
{"paths": [[0, 0]], "logp": [-2.253795]}
```

### DP 定义

令 `delta[t][j]` 表示处理到观测位置 `t`、最后状态为 `j` 时的最大对数概率。转移为：

```text
delta[t][j]
= max_i(delta[t-1][i] + log(A[i][j]))
  + log(B[j][obs[t]])
```

`psi[t][j]` 记录取得最大值的前驱状态，最后从最优终态反向恢复整条路径。

### 为什么使用对数域

原概率需要连续相乘，序列稍长就可能下溢为零。取对数后乘法变成加法；零概率映射为负无穷，仍能自然参与 `max`。

### Python ACM 实现

```python
import json

import numpy as np


def safe_log(probabilities: np.ndarray) -> np.ndarray:
    with np.errstate(divide="ignore"):
        return np.log(probabilities)


def viterbi(
    log_pi: np.ndarray,
    log_transition: np.ndarray,
    log_emission: np.ndarray,
    observations: list[list[int]],
) -> tuple[list[list[int]], list[float]]:
    state_count = len(log_pi)
    paths: list[list[int]] = []
    log_probabilities: list[float] = []

    for sequence in observations:
        length = len(sequence)
        delta = np.full((length, state_count), -np.inf)
        previous = np.zeros((length, state_count), dtype=np.int64)

        delta[0] = log_pi + log_emission[:, sequence[0]]

        for time in range(1, length):
            # 行是前驱状态，列是当前状态。
            scores = delta[time - 1, :, None] + log_transition
            previous[time] = np.argmax(scores, axis=0)
            delta[time] = (
                np.max(scores, axis=0)
                + log_emission[:, sequence[time]]
            )

        path = [0] * length
        path[-1] = int(np.argmax(delta[-1]))
        best_log_probability = float(delta[-1, path[-1]])

        for time in range(length - 2, -1, -1):
            path[time] = int(previous[time + 1, path[time + 1]])

        paths.append(path)
        log_probabilities.append(round(best_log_probability, 6))

    return paths, log_probabilities


data = json.loads(input())
pi = np.asarray(data["pi"], dtype=np.float64)
transition = np.asarray(data["A"], dtype=np.float64)
emission = np.asarray(data["B"], dtype=np.float64)
observations = [list(map(int, sequence)) for sequence in data["obs"]]

paths, logp = viterbi(
    safe_log(pi),
    safe_log(transition),
    safe_log(emission),
    observations,
)

print(json.dumps({"paths": paths, "logp": logp}))
```

### 正确性与复杂度

`delta[t][j]` 枚举了所有可能前驱并保留最大者，符合最优子结构。`psi` 保存每一步被选中的前驱，因此从最优终态回溯得到的路径恰好实现该最大概率。

- 单序列时间复杂度：`O(TN²)`；
- 单序列空间复杂度：`O(TN)`；
- 不要直接对概率连乘；
- 本题明确要求 NumPy，属于允许使用指定第三方库的特殊 ACM 题。

## 03 · 公倍数对和

### 题意重述

给定正整数 `x`，选择正整数 `a,b,c`，满足：

```text
lcm(a,b,c) = x
```

求最小的 `a+b+c`。

```text
输入
4
1
6
12
30

输出
3
6
8
10
```

### 把质因子幂视为不可拆分块

设：

```text
x = p₁^e₁ × p₂^e₂ × ... × pₘ^eₘ
```

每个完整质因子幂 `pᵢ^eᵢ` 至少要出现在 `a,b,c` 中的一个数里。把较小指数重复分配给多个数只会增大它们，却不会提高 LCM，所以存在最优解，使每个完整质因子幂只分配给三个数中的一个。

问题变为：把两两互质的 `m` 个乘法块分到三个盒子，使盒子乘积之和最小。DFS 枚举 `3^m` 种分配即可，并利用盒子对称性去重。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def prime_power_blocks(value: int) -> list[int]:
    blocks = []
    divisor = 2

    while divisor * divisor <= value:
        if value % divisor == 0:
            block = 1
            while value % divisor == 0:
                value //= divisor
                block *= divisor
            blocks.append(block)
        divisor += 1

    if value > 1:
        blocks.append(value)

    return blocks


def minimum_sum(value: int) -> int:
    blocks = prime_power_blocks(value)
    best = value + 2  # 对应 (value, 1, 1)
    boxes = [1, 1, 1]

    def dfs(index: int) -> None:
        nonlocal best

        if sum(boxes) >= best:
            return

        if index == len(blocks):
            best = min(best, sum(boxes))
            return

        used_products = set()
        for box in range(3):
            # 三个盒子中乘积相同的状态是对称的，只搜索一次。
            if boxes[box] in used_products:
                continue
            used_products.add(boxes[box])

            boxes[box] *= blocks[index]
            dfs(index + 1)
            boxes[box] //= blocks[index]

    dfs(0)
    return best


cache: dict[int, int] = {}
T = int(input())

for _ in range(T):
    x = int(input())
    if x not in cache:
        cache[x] = minimum_sum(x)
    print(cache[x])
```

### 正确性与复杂度

每个完整质因子幂被分配给至少一个数才能使 LCM 指数达标；重复分配不是必要的。DFS 枚举了所有必要分配，叶子结点都满足 LCM 为 `x`，取最小和即为答案。

- 质因数分解：`O(√x)`；
- DFS：最坏 `O(3^m)`，`m` 为不同质因子数量；
- 额外空间：`O(m)`；
- `x=1` 时三个数只能都取 `1`，答案为 `3`。
