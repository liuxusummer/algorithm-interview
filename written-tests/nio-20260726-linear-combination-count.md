## 题目描述

给定四个正整数 `x、y、l、r`。统计闭区间 `[l, r]` 中有多少个整数 `k` 可以写成：

```text
k = a × x + b × y
```

其中 `a、b` 可以是任意整数，包括负数和零。

## 输入格式

第一行输入一个整数 `T`，表示测试组数。

接下来 `T` 行，每行输入四个整数：

```text
x y l r
```

## 输出格式

对每组测试输出一行，一个整数，表示区间 `[l, r]` 内可以被表示的整数数量。

## 数据范围

- `1 <= T <= 10^5`
- `1 <= x, y, l, r <= 10^18`
- `l <= r`
- `a、b` 为任意整数，不限制非负

最后一条非常关键：若 `a、b` 只能取非负整数，问题会变成另一类可达性问题，不能直接使用本题结论。

## 样例

**输入**

```text
3
2 4 1 10
3 5 1 10
6 10 7 20
```

**输出**

```text
5
10
7
```

## 样例解释

- `x = 2、y = 4` 时，可表示数恰好是 `gcd(2, 4) = 2` 的倍数，`[1, 10]` 中共有 5 个；
- `x = 3、y = 5` 时，最大公约数为 1，因此区间内每个整数都能表示；
- `x = 6、y = 10` 时，可表示数是 2 的倍数，`[7, 20]` 中为 `8、10、12、14、16、18、20`，共 7 个。

## 从线性组合到最大公约数

设：

```text
g = gcd(x, y)
```

因为 `g` 同时整除 `x` 和 `y`，所以对任意整数 `a、b`：

```text
a × x + b × y
```

都一定是 `g` 的倍数。这说明：

> 能表示的整数，一定属于 `g` 的倍数集合。

但这只是必要性，还需要证明所有 `g` 的倍数都能表示。

## 裴蜀定理给出充分性

裴蜀定理说明：存在整数 `p、q`，使得：

```text
p × x + q × y = gcd(x, y) = g
```

等式两边同时乘任意整数 `m`：

```text
(m × p) × x + (m × q) × y = m × g
```

由于 `m × p` 和 `m × q` 仍然是整数，任意 `g` 的整数倍都可以表示。

结合必要性和充分性：

> 一个整数能写成 `a × x + b × y`，当且仅当它是 `gcd(x, y)` 的倍数。

原问题因此转化为：统计 `[l, r]` 中 `g` 的倍数数量。

## 闭区间倍数计数

在正整数区间 `[1, z]` 中，`g` 的倍数为：

```text
g, 2g, 3g, ..., floor(z / g) × g
```

数量是：

```text
floor(z / g)
```

所以 `[l, r]` 中的倍数数量可以用两个前缀相减：

```text
floor(r / g) - floor((l - 1) / g)
```

使用 `l - 1` 是为了正确包含左端点：当 `l` 本身是 `g` 的倍数时，它不应被左侧前缀扣除。

## 正确性证明

下面证明计算公式得到的结果就是答案。

**引理 1：任意可表示整数都是 `g` 的倍数。**

`g = gcd(x, y)` 同时整除 `x` 和 `y`，因此也整除任意整数线性组合 `a × x + b × y`。

**引理 2：任意 `g` 的倍数都可以表示。**

根据裴蜀定理，存在整数 `p、q` 使 `p × x + q × y = g`。对任意整数 `m`，取 `a = m × p、b = m × q`，就有 `a × x + b × y = m × g`。

由引理 1、2，可表示整数集合恰好等于 `g` 的所有整数倍。

`r // g` 精确统计 `[1, r]` 中的倍数数量，`(l - 1) // g` 精确统计 `[1, l - 1]` 中的倍数数量。二者相减后只留下 `[l, r]` 中的倍数，因此公式与题目答案完全相同。

## Python ACM 实现

```python
import sys
from math import gcd


def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    test_count = data[0]
    index = 1
    answers = []

    for _ in range(test_count):
        x, y, left, right = data[index : index + 4]
        index += 4

        divisor = gcd(x, y)

        # 用两个前缀相减，得到闭区间内 divisor 的倍数数量
        count = right // divisor - (left - 1) // divisor
        answers.append(str(count))

    sys.stdout.write("\n".join(answers))


if __name__ == "__main__":
    solve()
```

## 代码讲解

代码不需要真的求出裴蜀定理中的系数 `a、b`。题目只问“有多少个数可以表示”，只要用最大公约数刻画可表示集合即可。

一次性读取输入能减少大量测试组下的 I/O 开销。每组数据只执行一次 `gcd` 和常数次整数除法。

## 复杂度分析

欧几里得算法求 `gcd(x, y)` 的时间复杂度为：

```text
O(log min(x, y))
```

因此：

- 总时间复杂度：`O(T log min(x, y))`；
- 除输入与输出数组外，单组计算只使用 `O(1)` 额外空间；
- 当前一次性读取实现的总空间复杂度为 `O(T)`。

如果输入规模继续扩大，可以改用 `readline()` 流式处理，把算法额外空间降到 `O(1)`。

## 边界与易错点

1. `a、b` 可以为负数，这是使用裴蜀定理刻画全部倍数的前提；
2. 公式必须是 `right // g - (left - 1) // g`；
3. 当 `g = 1` 时，区间内所有整数都可以表示，答案为 `r - l + 1`；
4. 当区间内没有 `g` 的倍数时，答案自然为 `0`；
5. 数值达到 `10^18`，其他语言必须使用 64 位整数；
6. 本题不要求构造具体的 `a、b`，不要多做扩展欧几里得计算。

## 90 秒口述

我先设 `g = gcd(x, y)`。因为 `g` 整除 `x、y`，所以任意整数线性组合都是 `g` 的倍数；反过来，裴蜀定理保证存在整数系数把 `x、y` 组合成 `g`，等式乘任意整数后，所有 `g` 的倍数也都能表示。因此问题等价于统计 `[l, r]` 中 `g` 的倍数，答案是 `r // g - (l - 1) // g`。每组只需求一次最大公约数，复杂度为 `O(log min(x, y))`。
