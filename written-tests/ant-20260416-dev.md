## 01 · 仅含 1 和合数的数组

### 题意重述

给定 `n`，构造长度至少为 `2` 的正整数数组，使每个元素只能是 `1` 或合数，且元素和为 `n`。优先最小化数组长度。

```text
输入
3
8
10
2

输出
2
4 4
2
4 6
2
1 1
```

构造题通常允许输出任意一组最优合法方案；这里让样例输出与下方程序保持一致。

### 分类构造

长度不能小于 `2`，因此只要能构造两个数，答案就已经最优：

- 奇数 `n >= 7`：`[1, n-1]`，其中 `n-1` 是不小于 `6` 的偶合数；
- 偶数 `n >= 8`：`[4, n-4]`，其中 `n-4` 是不小于 `4` 的偶合数；
- `2..6` 逐一处理。

### Python ACM 实现

```python
import sys

input = sys.stdin.readline


def solve() -> None:
    n = int(input())

    special = {
        2: [1, 1],
        3: [1, 1, 1],
        4: [1, 1, 1, 1],
        5: [1, 4],
        6: [1, 1, 4],
    }

    if n in special:
        answer = special[n]
    elif n % 2 == 1:
        answer = [1, n - 1]
    else:
        answer = [4, n - 4]

    print(len(answer))
    print(*answer)


T = int(input())
for _ in range(T):
    solve()
```

### 正确性与复杂度

特殊值已经穷举验证。对更大的奇数与偶数，构造中的每个元素均为 `1` 或合数，且总和为 `n`；数组长度为理论下界 `2`，所以最短。

- 每组时间、空间复杂度均为 `O(1)`；
- `2` 和 `3` 是质数，不能作为数组元素。

## 02 · 剪绳子

### 题意重述

绳子上有编号 `1..n` 的点，相邻点距离为 `1`。支持：

- `1 x`：把点 `x` 标记为切点；
- `2 k`：询问当前切点将绳子分段后，是否存在长度至少为 `k` 的段。

`n` 可很大，不能按坐标开数组。

```text
输入
8 7
2 7
1 4
2 4
2 5
1 6
2 3
2 4

输出
YES
YES
NO
YES
NO
```

### 维护两个集合

插入切点 `x` 时，只会影响它左右最近切点 `left、right` 形成的旧间隔：

```text
right-left
→ x-left 与 right-x
```

因此需要：

1. 有序集合：查询前驱、后继并插入切点；
2. 间隔多重集合：删除旧长度、加入两个新长度、查询最大值。

Python 标准库没有平衡树，下面用随机 Treap 实现有序集合；最大间隔使用堆与计数器懒删除，避免依赖在线评测通常不提供的 `sortedcontainers`。

### Python ACM 实现

```python
import sys
import random
from collections import Counter
from heapq import heappop, heappush

input = sys.stdin.readline
sys.setrecursionlimit(1_000_000)


class Node:
    __slots__ = ("key", "priority", "left", "right")

    def __init__(self, key: int) -> None:
        self.key = key
        self.priority = random.randrange(1 << 30)
        self.left = None
        self.right = None


def split(root, key: int):
    if root is None:
        return None, None
    if root.key < key:
        root.right, right = split(root.right, key)
        return root, right
    left, root.left = split(root.left, key)
    return left, root


def insert(root, node: Node):
    if root is None:
        return node
    if node.priority > root.priority:
        node.left, node.right = split(root, node.key)
        return node
    if node.key < root.key:
        root.left = insert(root.left, node)
    else:
        root.right = insert(root.right, node)
    return root


def find_neighbors(root, key: int) -> tuple[int | None, int | None, bool]:
    predecessor = None
    successor = None

    while root is not None:
        if key < root.key:
            successor = root.key
            root = root.left
        elif key > root.key:
            predecessor = root.key
            root = root.right
        else:
            return predecessor, successor, True

    return predecessor, successor, False


class GapMultiset:
    def __init__(self, initial_gap: int) -> None:
        self.heap = [-initial_gap]
        self.count = Counter({initial_gap: 1})

    def add(self, gap: int) -> None:
        self.count[gap] += 1
        heappush(self.heap, -gap)

    def remove(self, gap: int) -> None:
        self.count[gap] -= 1

    def maximum(self) -> int:
        while self.heap and self.count[-self.heap[0]] == 0:
            heappop(self.heap)
        return -self.heap[0]


def solve() -> None:
    n, query_count = map(int, input().split())
    root = insert(None, Node(1))
    root = insert(root, Node(n))
    gaps = GapMultiset(n - 1)
    output = []

    for _ in range(query_count):
        operation, value = map(int, input().split())

        if operation == 1:
            left, right, exists = find_neighbors(root, value)
            if exists:
                continue

            # 新切点只拆分它所在的这一段。
            gaps.remove(right - left)
            gaps.add(value - left)
            gaps.add(right - value)
            root = insert(root, Node(value))
        else:
            output.append("YES" if gaps.maximum() >= value else "NO")

    print("\n".join(output))


solve()
```

### 正确性与复杂度

有序集合始终保存所有切点。插入时只有包含 `x` 的旧段发生改变，间隔多重集合按定义删除旧段并加入两条新段，因此它始终与真实分段一一对应；堆顶就是最长段。

- 期望时间复杂度：`O(Q log Q)`；
- 空间复杂度：`O(Q)`；
- 重复切同一点不能再次拆分间隔；
- 两端点 `1、n` 从一开始就是边界。

## 03 · 不互质元素下标

### 题意重述

给定数组 `a[1..n]`。每次查询 `(p,k)`，从 `p` 向右扫描，找第 `k` 个满足：

```text
gcd(a[i], a[p]) > 1
```

的位置 `i`，不存在则输出 `-1`。

```text
输入
6 3
2 3 4 6 5 9
1 2
2 1
3 3

输出
3
2
-1
```

### 质因子子集与容斥

两个数不互质，等价于共享至少一个质因子。对每个数组元素：

1. 分解出不同质因子；
2. 枚举所有非空质因子子集；
3. 把当前位置加入“子集乘积”对应的位置列表。

查询 `a[p]` 时，对其质因子子集做容斥，就能统计任意区间 `[p, right]` 内与它不互质的元素数量。计数随 `right` 单调不减，因此二分第一个计数达到 `k` 的位置。

### Python ACM 实现

```python
import sys
from bisect import bisect_left, bisect_right
from collections import defaultdict

input = sys.stdin.readline


def solve() -> None:
    n, query_count = map(int, input().split())
    values = [0] + list(map(int, input().split()))
    maximum = max(values)

    smallest_prime_factor = list(range(maximum + 1))
    for number in range(2, int(maximum**0.5) + 1):
        if smallest_prime_factor[number] == number:
            for multiple in range(number * number, maximum + 1, number):
                if smallest_prime_factor[multiple] == multiple:
                    smallest_prime_factor[multiple] = number

    factor_cache: dict[int, list[int]] = {1: []}

    def distinct_prime_factors(value: int) -> list[int]:
        if value in factor_cache:
            return factor_cache[value]

        original = value
        factors = []
        while value > 1:
            prime = smallest_prime_factor[value]
            factors.append(prime)
            while value % prime == 0:
                value //= prime

        factor_cache[original] = factors
        return factors

    factors_at = [[] for _ in range(n + 1)]
    positions: dict[int, list[int]] = defaultdict(list)

    for index in range(1, n + 1):
        factors = distinct_prime_factors(values[index])
        factors_at[index] = factors

        for mask in range(1, 1 << len(factors)):
            product = 1
            for bit, prime in enumerate(factors):
                if mask & (1 << bit):
                    product *= prime
            positions[product].append(index)

    def count_not_coprime(factors: list[int], left: int, right: int) -> int:
        total = 0

        for mask in range(1, 1 << len(factors)):
            product = 1
            selected = 0

            for bit, prime in enumerate(factors):
                if mask & (1 << bit):
                    product *= prime
                    selected += 1

            indices = positions[product]
            count = (
                bisect_right(indices, right)
                - bisect_left(indices, left)
            )
            total += count if selected % 2 == 1 else -count

        return total

    output = []

    for _ in range(query_count):
        start, rank = map(int, input().split())
        base_factors = factors_at[start]

        if count_not_coprime(base_factors, start, n) < rank:
            output.append("-1")
            continue

        left, right = start, n
        while left < right:
            middle = (left + right) // 2
            if count_not_coprime(base_factors, start, middle) >= rank:
                right = middle
            else:
                left = middle + 1

        output.append(str(left))

    print("\n".join(output))


solve()
```

### 正确性与复杂度

容斥式恰好统计“至少含一个公共质因子”的位置数；二分查找利用前缀计数的单调性，返回第一个计数不小于 `k` 的下标，正是第 `k` 个合法位置。

设一个数最多含 `m` 个不同质因子：

- 预处理：`O(V log log V + n·2^m·m)`；
- 单次查询：`O(2^m·m·log²n)`；
- 空间：`O(V + n·2^m)`；
- 当 `a[p]=1` 时质因子集合为空，答案一定是 `-1`。
