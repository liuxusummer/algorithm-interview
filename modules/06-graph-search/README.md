# 06 · 图、搜索与并查集

图题通常隐藏在依赖、路径、连通分量或状态转换的描述中。先明确节点、边和访问状态，再选择搜索方式。

这组题从“画出搜索树”开始，逐步过渡到网格连通分量和有向图拓扑排序。

## 本模块目标

- 能写出回溯的选择、约束、结束条件和撤销操作；
- 能区分排列、子集、切割三类搜索树；
- 能把二维网格抽象成四方向图；
- 能用迭代 DFS 避开 Python 递归深度风险；
- 能从依赖关系识别拓扑排序与有向环；
- 能根据边权选择 BFS、0-1 BFS 或 Dijkstra。

## 三类状态不要混

| 场景 | 访问状态生命周期 | 常见实现 |
|---|---|---|
| 单词路径 | 当前递归路径 | 标记后必须恢复 |
| 岛屿连通分量 | 整次算法 | 标记后不恢复 |
| 迷宫最短路径 | 第一次入队时的最短距离 | 入队时标记 |
| 拓扑排序 | 图的动态入度 | 删除边后入度递减 |

这是面试中最容易混淆的地方：同样叫“访问过”，是否恢复取决于状态代表的是当前路径，还是全局已经处理完成。

## Python 网格搜索检查表

- 空网格是否单独处理；
- 行列边界是否使用各自长度；
- 是四方向还是八方向；
- 入栈时标记，避免重复入栈；
- 求最短路时是否应改用队列并按层扩展；
- 是否允许修改输入；
- 递归深度是否可能超过 Python 默认限制。

## 最短路径选型

| 边权约束 | 推荐算法 | 典型复杂度 |
|---|---|---|
| 所有边权相同 | BFS | `O(V + E)` |
| 边权只有 0 和 1 | 0-1 BFS | `O(V + E)` |
| 边权均非负 | 堆优化 Dijkstra | `O((V + E) log V)` |
| 有向无环图 | 拓扑序 DP | `O(V + E)` |
| 允许负权边 | Bellman-Ford | `O(VE)` |
