# 07 · 动态规划与贪心

动态规划不是背转移方程，而是识别重复子问题，并把“做到这里的最优结果”定义成可计算状态。

贪心也不是“每次选看起来最大的”，而是要证明局部选择可以交换进任意最优解，或证明局部收益能够无损拆分。

## 本模块目标

- 能定义“以当前位置结尾”或“处理到当前位置”的 DP 状态；
- 能画出二维状态的依赖方向并安排遍历顺序；
- 能识别历史最优值可以压缩为常数变量的场景；
- 能用交换论证、上下界或收益拆分证明贪心；
- 能处理来自左右两个方向的局部约束；
- 能用单调结构让更优元素占据更高权重位置。

## 建议学习顺序

### 1. 从一维状态与滚动压缩开始

| 题目 | 核心状态 | 关键判断 |
|---|---|---|
| [070 · 爬楼梯](/problems/070-climbing-stairs) | 到达当前位置的方案数 | 最后一步来自哪里 |
| [198 · 打家劫舍](/problems/198-house-robber) | 前若干间房的最大收益 | 选当前还是跳过当前 |
| [053 · 最大子数组和](/problems/053-maximum-subarray) | 必须以当前位置结尾的最大和 | 延续旧区间还是重新开始 |

先写出完整 `dp` 定义和转移，再检查当前状态是否只依赖前一两个位置。依赖窗口固定时，可以用滚动变量压缩空间。

### 2. 前缀可达性与矩阵状态

| 题目 | 状态定义 | 转移来源 |
|---|---|---|
| [139 · 单词拆分](/problems/139-word-break) | 某个字符串前缀能否拆分 | 枚举最后一个单词 |
| [221 · 最大正方形](/problems/221-maximal-square) | 以当前格为右下角的最大边长 | 左、上、左上取最小 |

状态定义必须把答案需要的信息说完整。“以当前位置结尾”和“考虑到当前位置”含义不同，决定了转移能否成立。

### 3. 多维状态与序列匹配

| 题目 | 状态定义 | 依赖方向 |
|---|---|---|
| [005 · 最长回文子串](/problems/005-longest-palindromic-substring) | 一个闭区间是否回文 | 内部区间 |
| [064 · 最小路径和](/problems/064-minimum-path-sum) | 到达当前格的最小路径和 | 上、左 |
| [072 · 编辑距离](/problems/072-edit-distance) | 两个前缀的最少编辑次数 | 上、左、左上 |
| [718 · 最长重复子数组](/problems/718-maximum-length-of-repeated-subarray) | 以两个位置结尾的连续匹配长度 | 左上，不同则归零 |
| [1143 · 最长公共子序列](/problems/1143-longest-common-subsequence) | 两个前缀的最长公共子序列 | 左上或上、左 |

二维 DP 的遍历顺序由依赖关系决定。压缩空间前，先明确一维数组中的值属于上一行还是当前行；必要时逆序更新或保存左上旧值。

### 4. 背包模型与循环方向

| 题目 | 模型 | 一维更新方向 |
|---|---|---|
| [322 · 零钱兑换](/problems/322-coin-change) | 完全背包，硬币可重复使用 | 小金额到大金额 |
| [416 · 分割等和子集](/problems/416-partition-equal-subset-sum) | 0/1 背包，每个数字一次 | 目标和从大到小 |

一维压缩后，循环方向代表当前物品能否在同一轮重复使用。0/1 背包逆序，完全背包正序，这是需要理解状态新旧而不是死记的规则。

### 5. 从二次 DP 优化到二分

| 题目 | 基础方法 | 优化状态 |
|---|---|---|
| [300 · 最长递增子序列](/problems/300-longest-increasing-subsequence) | 枚举所有前驱，`O(n²)` | 每种长度的最小结尾，`O(n log n)` |

`tails` 不一定是实际子序列；它保存的是每个长度最有利于继续扩展的结尾值。

### 6. 维护历史最优与拆分局部收益

| 题目 | 贪心选择 | 正确性抓手 |
|---|---|---|
| [121 · 买卖股票的最佳时机](/problems/121-best-time-to-buy-and-sell-stock) | 维护此前最低价格 | 覆盖每个卖出日的最优交易 |
| [122 · 买卖股票的最佳时机 II](/problems/122-best-time-to-buy-and-sell-stock-ii) | 累加全部相邻正价差 | 上涨区间利润可以望远镜求和 |

121 也可以写成持有/未持有的状态 DP，但一次交易条件下，状态可以压缩为历史最低价格。

允许无限次交易且没有额外限制时，一段完整上涨与拆成每天交易的利润相同。加入手续费、冷冻期或次数上限后，这个结论不再成立，应切换到状态 DP。

### 7. 处理双向局部约束

| 题目 | 两次扫描 | 合并方式 |
|---|---|---|
| [135 · 分发糖果](/problems/135-candy) | 左侧约束 + 右侧约束 | 每个位置取两个下界的最大值 |

这类题单向扫描只能满足一半条件。第二次扫描不能直接覆盖第一次结果，否则可能破坏已经建立的约束。

### 8. 贪心与单调结构结合

| 题目 | 高权重目标 | 数据结构 |
|---|---|---|
| [402 · 移掉 K 位数字](/problems/402-remove-k-digits) | 让更小数字尽量靠左 | 单调不下降栈 |

当当前数字小于栈顶时，删掉更高位的大数字是安全交换；如果没有逆序对但仍需删除，则从低权重的末尾删除。

## 贪心证明工具箱

| 方法 | 证明问题 | 本模块例子 |
|---|---|---|
| 交换论证 | 能否把局部选择换进最优解 | 移掉 K 位数字 |
| 收益拆分 | 全局收益能否拆成独立局部收益 | 股票 II |
| 下界合并 | 每个位置至少需要多少资源 | 分发糖果 |
| 维护历史最优 | 当前决策只依赖哪个前缀统计量 | 股票 I |

## 股票题边界

| 限制 | 常见方法 |
|---|---|
| 最多一笔 | 历史最低价 |
| 无限次、无额外限制 | 累加正价差 |
| 含手续费 | 持有/未持有 DP |
| 含冷冻期 | 多状态 DP |
| 最多 `k` 笔 | 交易次数维度 DP |

## Python 实现检查表

- 答案是否允许“不做任何选择”；
- 状态初始化能否处理全负数或持续下跌；
- 一维背包的遍历方向是否符合物品使用次数；
- 布尔可达、方案数量和最小代价是否混淆；
- 矩阵 DP 压缩后是否保存了更新前的左上状态；
- 连续匹配失败时是否应该归零；
- 子串、子数组与子序列的连续性要求是否混淆；
- 严格递增与非递减是否选择了正确的二分边界；
- 相等元素是否需要触发约束；
- 第二次扫描是否会破坏第一次结果；
- 单调栈剩余删除次数是否正确处理；
- 字符串数字是否需要去除前导零；
- 声称局部最优前，是否能给出交换或上界证明。
