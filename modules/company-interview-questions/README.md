# 大厂面试真题

这里收录算法题之外的后端技术面试真题。首批只做 **12 道精选题**，每道题都包含直接回答、机制解释、易错点和常见追问。

## 来源说明

“大厂真题”来自候选人公开分享的面试记录，不是公司官方题库。同一家公司不同部门、职级和年份差异很大，因此本站遵循以下规则：

- 公开记录能直接看到问题时，才标注公司与岗位；
- 只引用问题，不照搬原帖答案；
- 技术答案重新依据官方文档、RFC 或论文核验；
- 不根据单条面经推算公司频次；
- 无法核对公司归属时，标为“跨面经高频”，不强贴公司标签。

## 推荐学习顺序

第一次学习按依赖顺序：

`CQ01 → CQ02 → CQ03 → CQ04 → CQ05 → CQ06 → CQ07 → CQ08 → CQ09 → CQ10 → CQ11 → CQ12`

面试前复习则按故障链路：

`客户端 → 网络 → 应用线程 → 缓存 → 数据库 → 消息队列 → 监控与排障`

## 通关标准

每道题至少做到：

1. 30 秒内给出直接结论；
2. 能画出流程或状态变化；
3. 能指出一个常见错误说法；
4. 能回答页面末尾的两个追问；
5. 知道答案依赖的实现或版本范围。
