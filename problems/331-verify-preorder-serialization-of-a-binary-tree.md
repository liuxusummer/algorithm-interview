## 题目

给定一串用逗号分隔的二叉树前序序列化：

- 整数表示非空结点；
- `#` 表示空结点。

在不重建二叉树的前提下，判断它是否是合法的二叉树序列化。

### 示例

```text
输入："9,3,4,#,#,1,#,#,2,#,6,#,#"
输出：True

输入："1,#"
输出：False

输入："9,#,#,1"
输出：False
```

## 槽位模型

把“等待一个结点填入的位置”称为槽位：

- 开始时根结点需要一个槽位，所以 `slots = 1`；
- 每读到一个标记，先消费一个槽位；
- `#` 不产生新槽位；
- 非空结点有左右孩子，因此产生两个新槽位。

任何时刻槽位变成负数，都说明出现了没有父结点可接纳的标记。扫描结束后槽位必须恰好为零。

## Python 实现

```python
class Solution:
    def isValidSerialization(self, preorder: str) -> bool:
        slots = 1

        for index, char in enumerate(preorder):
            if index > 0 and preorder[index - 1] != ",":
                continue

            slots -= 1

            if slots < 0:
                return False

            if char != "#":
                slots += 2

        return slots == 0
```

## 为什么不能只在最后检查

`"#,1"` 最终槽位变化可能让人误以为只看总量即可，但根的 `#` 已经封闭整棵树，后面的 `1` 没有任何位置可挂接。

所以必须保证每个前缀消费结点前都有可用槽位，也就是过程中 `slots` 不能小于零。

## 正确性说明

合法二叉树前序序列化中，每个标记恰好占用父结点提供的一个槽位，非空结点再准确提供两个孩子槽位。因此任意前缀都不会超额消费，完整扫描后所有槽位恰好填满。反之，如果过程从不缺槽位且最终为零，每个标记都有合法父位置，且不存在未填孩子位置或多余结点，序列化合法。

## 复杂度

- 时间复杂度：`O(n)`，逐字符识别每个标记的起点。
- 空间复杂度：`O(1)`，只维护槽位计数与扫描下标。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---|---|
| `"#"` | `True` | 空树 |
| `"1,#,#"` | `True` | 单结点 |
| `"1,#"` | `False` | 槽位未填满 |
| `"9,#,#,1"` | `False` | 树结束后还有结点 |
| `"#,1"` | `False` | 前缀槽位不足 |

## 90 秒面试表达

“不用真的建树，可以统计待填的孩子槽位。根先提供一个槽位，每读一个标记先消耗一个；如果是非空结点，再产生两个孩子槽位，`#` 不产生。过程中槽位小于零说明出现多余结点，结束时不为零说明还有孩子位置没填。一次扫描 `O(n)`，计数变量是 `O(1)` 空间。”

## 常见追问

- 也可以用栈不断把“结点,#,#”归约成 `#`，但空间为 `O(n)`。
- 对一般 `k` 叉树，非空结点产生 `k` 个槽位。
- 中序序列化即使包含空结点，通常也不能唯一确定树结构。
