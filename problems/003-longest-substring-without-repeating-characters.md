## 题目

给定一个字符串 `s`，请找出其中不含重复字符的最长连续子串，并返回它的长度。

子串必须连续；只需要返回长度，不需要返回子串本身。

### 示例

```text
输入：s = "abcabcbb"
输出：3
解释：最长无重复子串可以是 "abc"，长度为 3
```

```text
输入：s = "bbbbb"
输出：1
解释：最长无重复子串是 "b"
```

### 约束观察

- 题目要求连续子串，适合使用滑动窗口。
- 当窗口内出现重复字符时，左边界必须越过该字符上一次出现的位置。
- 左边界只能向右移动，不能因为遇到更早的重复记录而后退。

## 先说暴力解

枚举每个起点，再向右扩展，并用集合判断字符是否重复。一旦重复就停止当前起点的扩展。

最坏情况下，每个起点都要扫描到字符串末尾，时间复杂度为 `O(n²)`。

## 优化抓手

维护窗口 `[left, right]`，保证窗口内始终没有重复字符。哈希表记录每个字符最近一次出现的下标。

当字符 `char` 上一次出现在当前窗口内时：

```text
left = last_seen[char] + 1
```

更新左边界后，窗口重新满足“所有字符互不重复”。由于每个下标最多被左右边界各访问一次，整体可以在线性时间完成。

## Python 实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_seen: dict[str, int] = {}
        left = 0
        best_length = 0

        for right, char in enumerate(s):
            if char in last_seen and last_seen[char] >= left:
                left = last_seen[char] + 1

            last_seen[char] = right
            best_length = max(best_length, right - left + 1)

        return best_length
```

## 为什么要判断 `last_seen[char] >= left`

哈希表保存的是字符在整个扫描过程中的最后位置，它可能已经落在当前窗口左侧。

例如 `s = "abba"`。处理最后一个 `a` 时，旧位置 `0` 已经不在当前窗口中。如果直接把 `left` 改成 `1`，左边界会从 `2` 错误后退。只有旧位置仍在窗口内时才移动左边界。

## 正确性说明

每轮开始时，窗口 `[left, right - 1]` 中没有重复字符。加入 `s[right]` 后，如果它与窗口内字符重复，就把 `left` 移到旧字符后一位，恰好删除这次重复；如果旧位置在窗口外，则无需调整。更新后窗口仍然无重复，算法检查每个右边界对应的最长合法窗口，因此不会漏掉最优答案。

## 复杂度

- 时间复杂度：`O(n)`。右边界扫描一次，左边界只向右移动。
- 空间复杂度：`O(min(n, Σ))`，其中 `Σ` 是字符集大小。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `""` | 0 | 空字符串 |
| `"a"` | 1 | 单字符 |
| `"bbbbb"` | 1 | 全部重复 |
| `"abba"` | 2 | 左边界不能后退 |
| `"pwwkew"` | 3 | 多段重复 |

## 90 秒面试表达

“暴力解会从每个起点向右扩展，最坏是 `O(n²)`。我用滑动窗口维护一个没有重复字符的区间，并用哈希表记录每个字符最近出现的下标。当右边界遇到窗口内的重复字符时，把左边界移动到旧位置的下一位。需要判断旧位置是否仍在当前窗口内，避免左边界后退。每个位置只被线性扫描，时间 `O(n)`，空间由窗口中的字符种类决定。”

## 常见追问

- 如果要返回具体子串，同时记录最佳窗口的起点即可。
- 如果字符集固定且很小，可以用定长数组代替哈希表。
- 如果输入是数据流，可以保留当前窗口状态和最近位置表持续处理。
