## 题目

给定一个字符串 `s`，请找出其中不含重复字符的最长连续子串，并返回它的长度。

子串必须连续；只需要返回长度，不需要返回子串本身。

### 示例

```text
输入：s = "abcabcbb"
输出：3
解释：最长无重复子串可以是 "abc"，长度为 3
```

```text
输入：s = "bbbbb"
输出：1
解释：最长无重复子串是 "b"
```

### 约束观察

- 题目要求连续子串，适合使用滑动窗口。
- 集合可以直接判断新字符是否已经存在于当前窗口。
- 当窗口内出现重复字符时，不断移动左边界，直到重复字符被移出窗口。
- 左右边界都只向右移动，每个字符最多进入和离开窗口各一次。

## 先说暴力解

枚举每个起点，再向右扩展，并用集合判断字符是否重复。一旦重复就停止当前起点的扩展。

最坏情况下，每个起点都要扫描到字符串末尾，时间复杂度为 `O(n²)`。

## 优化抓手

维护窗口 `[left, right]`，并用集合 `window` 保存窗口内的全部字符。

加入 `s[right]` 之前，如果它已经存在于集合中，说明窗口出现重复。此时持续移除左端字符并右移 `left`：

```text
while s[right] in window:
    移除 s[left]
    left += 1
```

循环结束后，新字符与窗口内所有字符都不同，再把它加入集合。由于每个字符最多进入和离开窗口各一次，整体可以在线性时间完成。

## Python 实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # window 保存当前滑动窗口中的所有字符。
        # 循环结束时始终保证窗口内没有重复字符。
        window = set()
        left = 0
        ans = 0

        # right 依次作为窗口右边界，尝试把 s[right] 加入窗口。
        for right in range(len(s)):
            # 如果新字符已在窗口中，就持续收缩左边界。
            # 必须使用 while，因为可能要移除多个字符才能消除重复。
            while s[right] in window:
                window.remove(s[left])
                left += 1

            # 此时 s[right] 与窗口内所有字符都不同，可以安全加入。
            window.add(s[right])

            # 当前合法窗口是闭区间 [left, right]。
            ans = max(ans, right - left + 1)

        return ans
```

## 为什么收缩窗口必须使用 `while`

集合只告诉我们“当前字符在窗口中”，没有记录重复字符的具体位置。因此需要从左侧逐个移除字符，直到旧的重复字符离开窗口。

例如：

```text
s = "pwwkew"
```

处理第二个 `w` 时，窗口是 `"pw"`。先移除 `p` 后，窗口里仍然有 `w`，所以还要继续移除第一个 `w`。如果只写 `if`，新 `w` 加入后窗口中仍有重复字符。

## 正确性说明

每轮开始时，集合恰好保存窗口 `[left, right - 1]` 内的字符，并且窗口中没有重复。若 `s[right]` 已在集合中，`while` 循环持续移除窗口左端字符，直到旧的 `s[right]` 被移出；此时加入新字符后，窗口仍然没有重复。对于固定的右边界，算法保留了能够得到的最靠左合法边界，因此当前窗口是以该位置结尾的最长无重复子串。枚举所有右边界并取最大长度，就不会遗漏全局最优答案。

## 复杂度

- 时间复杂度：`O(n)`。右边界扫描一次，左边界只向右移动。
- 空间复杂度：`O(min(n, Σ))`，其中 `Σ` 是字符集大小。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `""` | 0 | 空字符串 |
| `"a"` | 1 | 单字符 |
| `"bbbbb"` | 1 | 全部重复 |
| `"abba"` | 2 | 左边界不能后退 |
| `"pwwkew"` | 3 | 多段重复 |

## 90 秒面试表达

“暴力解会从每个起点向右扩展，最坏是 `O(n²)`。我用滑动窗口和集合维护一个没有重复字符的区间。右边界加入新字符前，如果集合中已经有它，就不断移除左端字符并右移左边界，直到重复消失；然后加入新字符并更新窗口最大长度。每个字符最多进入和离开集合各一次，所以时间是 `O(n)`，空间由窗口中的字符种类决定。”

## 常见追问

- 如果要返回具体子串，同时记录最佳窗口的起点即可。
- 如果字符集固定且很小，可以用定长数组代替哈希表。
- 如果改用哈希表记录字符最近出现的位置，可以让左边界一次跳到重复字符之后。
- 如果输入是数据流，可以保留当前窗口集合和左右边界状态持续处理。
