## 题目

给定长度为 `n` 的整数数组 `height`。第 `i` 条竖线端点为 `(i, 0)` 和 `(i, height[i])`。

选择两条竖线与横轴组成容器，返回能够容纳的最大水量。

### 示例

```text
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：选择下标 1 和 8，宽度为 7，高度由较短的 7 决定，面积为 49。
```

### 约束观察

- 至少需要两条竖线才能形成容器；
- 容量同时受宽度和短板高度限制；
- 指针向内移动后宽度只会变小，因此必须寻找能安全淘汰一侧的依据。

## 先说暴力解

枚举任意两条竖线，计算它们形成的面积并取最大值。共有 `O(n²)` 对组合，数据规模较大时会超时。

## 思路：向内移动短板

左右指针从数组两端开始。当前面积为：

```text
(right - left) × min(height[left], height[right])
```

宽度每次都会缩小。要让面积有机会变大，只能尝试提高短板，因此移动高度较小的一侧；移动长板无法突破原来的短板高度，面积一定不会更大。

## Python 实现

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        best = 0

        while left < right:
            width = right - left
            current_height = min(height[left], height[right])
            best = max(best, width * current_height)

            # 容量由短板限制，只移动短板才可能提高有效高度。
            if height[left] <= height[right]:
                left += 1
            else:
                right -= 1

        return best
```

## 正确性说明

假设左板不高于右板。保持左板、把右指针向内移动时，宽度变小，而有效高度最多仍是左板高度，因此不可能得到更大面积。丢弃左板不会漏掉最优解。右板较短时同理。

算法每次安全地排除一条不可能参与更优答案的边，最终考察到最优组合。

## 复杂度

- 两个指针一共移动不超过 `n` 次，时间 `O(n)`；
- 只使用常数变量，空间 `O(1)`。

## 边界用例

| 输入 | 输出 | 检查点 |
|---|---:|---|
| `[1, 1]` | `1` | 最短合法数组 |
| `[1, 2, 1]` | `2` | 最优解可能使用两个端点 |
| `[0, 3, 0]` | `0` | 高度允许为零 |
| `[4, 3, 2, 1, 4]` | `16` | 两端等高时移动任意一侧均安全 |

## 90 秒面试表达

暴力枚举两条边是 `O(n²)`。优化时让指针从两端出发，当前面积由宽度乘短板高度决定。宽度下一步必然减小，如果移动长板，短板仍然限制高度，面积不可能变大；所以每次只移动短板并更新最大值。这样每条边最多访问一次，时间 `O(n)`、空间 `O(1)`。

## 常见追问

- 为什么不是移动高板：高板移动后短板仍限制高度，宽度还变小；
- 两边相等时移动任意一边都安全；
- 本题不能使用接雨水的逐位置累计方式，两题目标不同。
