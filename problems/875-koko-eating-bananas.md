## 题目

有若干堆香蕉。珂珂每小时选择一堆，最多吃 `k` 根；如果该堆不足 `k` 根则吃完这一堆。给定总时限 `h`，求能在时限内吃完全部香蕉的最小速度 `k`。

### 示例

```text
输入：piles = [3, 6, 7, 11], h = 8
输出：4
解释：速度 4 需要 1 + 2 + 2 + 3 = 8 小时；速度 3 需要 10 小时。
```

### 约束观察

- 每堆至少占用一小时，题目保证 `h` 足以完成；
- 速度下界为 `1`，上界取 `max(piles)` 一定可行；
- 速度增大时，总耗时不会增加，满足二分答案的单调性。

## 先说逐个尝试

从速度 `1` 开始逐个验证，最坏要尝试到最大堆大小 `M`，时间为 `O(nM)`。由于“能否按时吃完”随速度单调变化，可以用二分跳过大量无效速度。

## 答案二分

速度越快，所需时间越短，答案具有单调性。速度范围是 `[1, max(piles)]`，可以二分查找第一个满足总耗时不超过 `h` 的速度。

## Python 实现

```python
from typing import List


class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        left, right = 1, max(piles)

        while left < right:
            speed = (left + right) // 2
            # 向上取整：一堆香蕉至少占用一个完整小时
            hours = sum((pile + speed - 1) // speed for pile in piles)

            if hours <= h:
                right = speed
            else:
                left = speed + 1

        return left
```

## 正确性说明

若速度 `k` 可行，则所有更大的速度也可行；若 `k` 不可行，则所有更小的速度也不可行。二分始终保留最小可行速度所在区间，区间收缩到一个值时，该值就是答案。

### 示例中的二分过程

| 候选速度 | 总耗时 | 结论 | 新区间 |
|---:|---:|---|---|
| `6` | `6` | 可行，继续找更小值 | `[1, 6]` |
| `3` | `10` | 不可行 | `[4, 6]` |
| `5` | `8` | 可行 | `[4, 5]` |
| `4` | `8` | 可行且为最小值 | `[4, 4]` |

## 复杂度

- 时间：`O(n log M)`，`M` 为最大香蕉堆
- 空间：`O(1)`

## 边界用例

| `piles` | `h` | 输出 | 检查点 |
|---|---:|---:|---|
| `[1]` | `1` | `1` | 最小输入 |
| `[30, 11, 23, 4, 20]` | `5` | `30` | 每堆只能占一小时 |
| `[30, 11, 23, 4, 20]` | `6` | `23` | 最小可行边界 |

## 90 秒面试表达

固定速度后可以在线性时间计算总耗时，并且速度越大耗时越短，所以答案具有单调性。我在 `[1, max(piles)]` 上二分第一个可行速度。中点可行就收缩右边界，否则排除中点及其左侧。单堆耗时用向上取整，最终左右边界相遇的位置就是最小速度。

## 常见追问

- 单堆耗时必须向上取整，不能使用普通整除；
- 为什么上界是最大堆：此时每堆至多一小时；
- 二分目标是“第一个可行值”，可行时不能直接返回中点。
