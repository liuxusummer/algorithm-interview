## 题目

给定字符数组 `s`，要求原地反转，不能额外创建另一个同规模数组。

### 示例

```text
输入：s = ["h", "e", "l", "l", "o"]
修改后：["o", "l", "l", "e", "h"]
```

### 约束观察

- 函数直接修改输入数组，不需要返回新字符串；
- 原地要求排除了切片复制等 `O(n)` 额外空间写法；
- 反转后的下标 `i` 与原下标 `n-1-i` 成对对应。

## 先说语言内置写法

Python 的 `s.reverse()` 可以原地反转。但面试通常希望看到指针移动和空间分析，因此手写双指针更能表达通用方法。

## 双指针思路

左右指针分别从数组两端出发，交换对应字符，然后同时向中间移动。

## Python 实现

```python
from typing import List


class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1

        while left < right:
            # 原地交换两端字符，不申请额外数组
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```

## 正确性说明

每轮将当前左右位置放入它们反转后应在的位置。循环结束时，所有对称位置均已交换，中间字符（若有）无需处理，因此整个数组被正确反转。

## 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 边界用例

| 输入 | 修改后 | 检查点 |
|---|---|---|
| `[]` | `[]` | 空数组 |
| `["a"]` | `["a"]` | 单字符无需交换 |
| `["a", "b"]` | `["b", "a"]` | 最小交换 |
| `["a", "b", "a"]` | `["a", "b", "a"]` | 奇数长度中点不动 |

## 90 秒面试表达

反转数组时，下标 `i` 应与 `n-1-i` 交换。我用左右指针从两端向中间移动，每轮交换一对字符；当两指针相遇或交错时，所有对称位置都已经就位。每个元素最多处理一次，时间 `O(n)`，只用两个指针，空间 `O(1)`。

## 常见追问

- 字符串不可变时，需要创建字符数组或返回切片；
- `s[:] = reversed(s)` 会修改原数组，但会产生额外序列；
- 奇数长度数组的中间字符无需处理。
