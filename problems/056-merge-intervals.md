## 题目

给定一组闭区间 `intervals`，其中每个区间表示为 `[start, end]`。合并所有重叠区间，并返回互不重叠、覆盖范围不变的区间列表。

### 示例

```text
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
```

```text
输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
```

### 约束观察

- 输入区间不一定有序。
- 区间按起点排序后，只需要与当前最后一个合并结果比较。
- 闭区间端点相等也算重叠，因此判断条件是 `start <= last_end`。

## 直接方案

反复寻找任意一对重叠区间并合并，直到没有重叠。这个过程需要多轮扫描，最坏可能达到 `O(n³)`，而且实现容易遗漏合并后的新关系。

排序可以把可能重叠的区间变成相邻关系。

## 优化抓手

先按区间起点升序排序。设当前已经合并的最后区间为 `[last_start, last_end]`：

- 如果新起点 `start <= last_end`，两个区间重叠，扩展右端点；
- 否则新旧区间分离，把新区间加入结果。

因为后续区间的起点只会更大，一旦与最后结果不重叠，也不可能与更早的结果重叠。

## Python 实现

```python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        if not intervals:
            return []

        ordered_intervals = sorted(
            intervals,
            key=lambda interval: interval[0],
        )
        merged = [ordered_intervals[0][:]]

        # 按起点排序后，只需与最后一个已合并区间比较。
        for start, end in ordered_intervals[1:]:
            last_interval = merged[-1]

            if start <= last_interval[1]:
                last_interval[1] = max(last_interval[1], end)
            else:
                merged.append([start, end])

        return merged
```

## 为什么只比较最后一个结果

结果列表中的区间已经互不重叠，并按起点排序。新来的区间如果连起点最大的最后区间都不重叠，那么它的起点更不可能落入此前右端点更小的区间。

如果它与最后区间重叠，合并后仍然只需要更新最后区间，不会影响更早部分。

## 为什么复制第一个区间

```python
merged = [ordered_intervals[0][:]]
```

后续代码会修改右端点。复制可以避免修改调用者传入的内部列表，让函数除返回值外没有额外副作用。

## 正确性说明

排序后，算法按起点从小到大处理区间。处理每个新区间前，`merged` 已经是已扫描区间的正确合并结果。新区间只可能与最后结果重叠：重叠时扩展其右端点，不重叠时追加新区间。两种操作都保持结果有序且互不重叠，因此处理完成后得到全部区间的正确合并。

## 复杂度

- 时间复杂度：`O(n log n)`，主要来自排序；扫描为 `O(n)`。
- 空间复杂度：`O(n)`，用于排序副本和返回结果。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---|---|
| `[[1,3],[2,6],[8,10],[15,18]]` | `[[1,6],[8,10],[15,18]]` | 基础路径 |
| `[[1,4],[4,5]]` | `[[1,5]]` | 端点相接 |
| `[[1,4],[2,3]]` | `[[1,4]]` | 完全包含 |
| `[[5,7],[1,2]]` | `[[1,2],[5,7]]` | 输入无序 |
| `[]` | `[]` | 空输入 |

## 90 秒面试表达

“直接反复找重叠关系会很复杂。我先按起点排序，这样可能重叠的区间会相邻。遍历时只比较当前区间和结果中的最后一个区间：如果当前起点不大于最后右端点，就更新右端点为两者最大值；否则直接追加。闭区间端点相等也要合并。排序是 `O(n log n)`，扫描是 `O(n)`，空间 `O(n)`。”

## 常见追问

- 如果输入已经按起点排序，可以省去排序，时间降为 `O(n)`。
- 插入新区间可以先保留左侧不重叠区间，再合并中间部分，最后追加右侧区间。
- 如果区间是左闭右开，需要根据业务语义重新判断端点相接是否算重叠。
