## 题目

每个人用 `[h, k]` 表示：身高为 `h`，其前方恰好有 `k` 个身高大于或等于 `h` 的人。请重建满足条件的队列。

### 示例

```text
输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

### 约束观察

- `k` 只统计身高不低于当前人的前方人数；
- 先安排矮个子会被后续高个子插入破坏；
- 先安排高个子后，后续更矮的人不会影响高个子的 `k`。

## 先说直接试排

逐个尝试所有队列排列并检查条件会产生阶乘级组合。贪心的关键是找到一种处理顺序，使已经满足的约束不会被后续操作破坏。

## 贪心思路

先按身高从高到低排序，身高相同时按 `k` 从小到大排序。依次将每个人插入结果的下标 `k`；因为已经放入的人都不矮于当前人，插入位置就是其前方高个子数量。

## Python 实现

```python
from typing import List


class Solution:
    def reconstructQueue(self, people: List[List[int]]) -> List[List[int]]:
        people.sort(key=lambda person: (-person[0], person[1]))
        queue = []

        for person in people:
            # 已入队者都不矮于当前人，直接插到 k 位置
            queue.insert(person[1], person)

        return queue
```

## 正确性说明

处理当前人时，结果中所有人身高均不小于他，因此插入下标 `k` 可确保前方恰有 `k` 个不矮于他的人。之后插入的更矮者不会影响这个计数，所以每一步建立的条件都保持成立。

### 插入轨迹

排序后：

```text
[7,0], [7,1], [6,1], [5,0], [5,2], [4,4]
```

依次插入：

```text
[[7,0]]
[[7,0],[7,1]]
[[7,0],[6,1],[7,1]]
[[5,0],[7,0],[6,1],[7,1]]
[[5,0],[7,0],[5,2],[6,1],[7,1]]
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

## 复杂度

- 时间：`O(n²)`，列表中间插入需要移动元素
- 空间：`O(n)`

## 边界用例

| 输入 | 检查点 |
|---|---|
| `[[5,0]]` | 单人队列 |
| `[[5,0],[5,1],[5,2]]` | 身高相同时必须按 `k` 升序 |
| `[[6,0],[5,0]]` | 矮个子可插到高个子前，不影响高个子的条件 |

## 90 秒面试表达

关键是先处理高个子。高个子的位置不会受后续矮个子影响，所以按身高降序、`k` 升序排列，再把每个人插入下标 `k` 即可。

## 常见追问

- 同身高为什么按 `k` 升序：否则较大的插入位置可能尚不存在，且会破坏同身高计数；
- Python 列表中间插入为 `O(n)`，所以总体不是 `O(n log n)`；
- 若数据规模很大，可用树状数组寻找第 `k` 个空位处理另一种排序方式。
