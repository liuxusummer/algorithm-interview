> 本页采用腾讯 IEG 公开面经中的数字版题面：相邻两位数字之和为 `10` 时消除，反复处理后返回剩余长度。它与常见的“相同字符消除”不是同一道题。公开题库中没有与本页规则完全相同的力扣题，因此不附“力扣原题”按钮。

## 题目

给定一个只包含数字 `1` 到 `9` 的字符串 `digits`。

如果相邻两个数字之和等于 `10`，就可以同时消除这两个数字。消除后，左右两部分重新相邻，可能继续触发新的消除。

请反复执行消除，直到无法继续，返回最终字符串的长度。

### 接口约定

```text
remainingLength(digits) -> int
```

### 数据范围

- `0 <= len(digits) <= 10^5`；
- `digits` 中的每个字符都在 `'1'` 到 `'9'` 之间。

## 示例一

```text
输入：digits = "137285"
输出：2
```

消除过程：

```text
137285
1  285    # 3 + 7 = 10
1   5     # 2 + 8 = 10
```

最终剩下 `"15"`，长度为 `2`。

## 示例二

```text
输入：digits = "1937"
输出：0
```

先消除 `1` 和 `9`，剩下 `"37"`；再消除 `3` 和 `7`，最终为空串。

## 为什么想到栈

从左到右处理字符串时，新数字只可能和“当前尚未消除部分的最后一个数字”相邻。

因此用栈保存已经处理过、暂时无法消除的数字：

1. 栈非空且栈顶与当前数字之和为 `10`：弹出栈顶，两者一起消除；
2. 否则：把当前数字压栈；
3. 扫描结束后，栈内就是最终剩余字符串。

消除可能带来的连锁反应也不需要额外回溯。弹栈后，更早的数字会重新成为栈顶，后续数字到来时自然会继续比较。

## Python 实现

```python
class Solution:
    def remainingLength(self, digits: str) -> int:
        stack: list[int] = []

        for character in digits:
            current = ord(character) - ord("0")

            if stack and stack[-1] + current == 10:
                # 栈顶就是当前数字在剩余串中的左邻居；
                # 两数之和为 10 时同时消除。
                stack.pop()
            else:
                # 当前数字暂时不能消除，保留给后续数字匹配。
                stack.append(current)

        return len(stack)
```

## 执行过程

以 `digits = "137285"` 为例：

| 当前数字 | 操作 | 栈 |
|---|---|---|
| `1` | 无可匹配数字，入栈 | `[1]` |
| `3` | `1 + 3 != 10`，入栈 | `[1, 3]` |
| `7` | `3 + 7 == 10`，弹栈 | `[1]` |
| `2` | `1 + 2 != 10`，入栈 | `[1, 2]` |
| `8` | `2 + 8 == 10`，弹栈 | `[1]` |
| `5` | `1 + 5 != 10`，入栈 | `[1, 5]` |

最终栈长为 `2`。

## 正确性说明

处理完任意前缀后，栈从底到顶恰好保存这个前缀充分消除后的剩余数字，并且栈内不存在相邻数字之和为 `10` 的情况。

加入下一个数字 `current` 时：

- 它左侧唯一可能立即与它消除的数字，就是当前剩余串末尾，也就是栈顶；
- 如果二者之和为 `10`，弹出栈顶正好完成这次消除；
- 如果二者之和不为 `10`，当前数字无法和更靠左的数字跨过栈顶相邻，只能入栈。

两种操作后，栈仍然是已处理前缀充分消除后的结果。根据数学归纳法，扫描完整个字符串后，栈中保存的就是最终剩余串，因此返回其长度正确。

## 复杂度

每个数字最多：

- 入栈一次；
- 出栈一次。

所以：

- 时间复杂度为 `O(n)`；
- 最坏情况下没有任何数字被消除，栈占用 `O(n)` 空间。

## 边界用例

| 输入 | 说明 | 输出 |
|---|---|---:|
| `""` | 空串 | `0` |
| `"5"` | 单个数字 | `1` |
| `"55"` | `5 + 5 = 10` | `0` |
| `"123"` | 无法消除 | `3` |
| `"1937"` | 连续发生两次消除 | `0` |
| `"137285"` | 两组数字被消除 | `2` |

## 如果要求返回剩余字符串

只需把栈中的整数重新拼接：

```python
def remaining_string(digits: str) -> str:
    stack: list[str] = []

    for character in digits:
        if (
            stack
            and int(stack[-1]) + int(character) == 10
        ):
            stack.pop()
        else:
            stack.append(character)

    return "".join(stack)
```

## 60～90 秒口述稿

这道题的关键是消除之后会形成新的相邻关系，所以我用栈保存当前还没被消除的数字。

从左到右扫描时，当前数字只可能和剩余串的最后一个数字发生消除，也就是栈顶。如果两数之和为 10，就弹出栈顶；否则把当前数字入栈。弹栈之后，更早的数字重新暴露出来，后续扫描会自然处理连锁消除。

每个数字最多入栈和出栈一次，所以时间复杂度是 `O(n)`；最坏情况下全部保留，空间复杂度是 `O(n)`。

## 常见追问

### 1. 为什么不能在原字符串上反复删除？

字符串删除通常需要搬移后续内容。最坏情况下反复扫描和删除会退化到 `O(n²)`，栈可以在线性时间完成同样的归约。

### 2. 如果消除条件改成相同字符呢？

栈框架不变，只需把条件改成 `stack[-1] == current`。[删除字符串中的所有相邻重复项 1047](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)是这类规则的相关练习，但不是本题。

### 3. 如果要统计消除了多少对？

每次执行 `pop` 时把计数器加一即可。若原长度为 `n`、剩余长度为 `r`，消除对数也等于 `(n - r) // 2`。
