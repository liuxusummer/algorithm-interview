## 题目

一面矩形砖墙由多行砖块组成，每行总宽度相同。画一条从顶部到底部的竖线，求它穿过的最少砖块数。

竖线可以经过砖块之间的缝隙，但不能沿着墙的左右边缘。

### 示例

```text
输入：wall = [
  [1, 2, 2, 1],
  [3, 1, 2],
  [1, 3, 2],
  [2, 4],
  [3, 1, 2],
  [1, 3, 1, 1]
]
输出：2
```

### 约束观察

- 每一行总宽度相同，但砖块切分方式不同；
- 真正影响答案的是“内部缝隙的横坐标”，不是砖块宽度本身；
- 墙宽可能很大，不能逐个横坐标尝试竖线。

## 先说直观解

可以枚举竖线位置，再逐行判断它是否穿过砖块。但坐标范围可能远大于砖块数量，逐坐标扫描会浪费大量时间。应当只统计真正可能减少穿砖数的位置，也就是各行内部缝隙。

## 思路：寻找最多缝隙

竖线穿过的砖块数等于：

```text
总行数 - 竖线经过的内部缝隙数
```

对每一行计算砖块宽度前缀和，它代表内部缝隙的横坐标。用哈希表统计每个横坐标出现于多少行，取最大值即可。

最后一块砖后的前缀和是墙的右边缘，必须排除。

## Python 实现

```python
from collections import defaultdict


class Solution:
    def leastBricks(self, wall: list[list[int]]) -> int:
        gap_counts: dict[int, int] = defaultdict(int)

        for row in wall:
            position = 0

            # 不统计最后一块砖之后的墙体右边缘。
            for width in row[:-1]:
                position += width
                gap_counts[position] += 1

        most_gaps = max(gap_counts.values(), default=0)
        return len(wall) - most_gaps
```

## 正确性说明

对于任意内部横坐标，每一行要么在这里存在缝隙，要么竖线穿过一块砖。哈希表记录存在缝隙的行数，因此 `行数 - 缝隙数` 正是穿过的砖块数。选择缝隙数最多的位置，就等价于让穿过砖块数最少。

## 复杂度

令砖块总数为 `B`：

- 每块非末尾砖只处理一次，时间复杂度 `O(B)`；
- 最多记录 `O(B)` 个不同缝隙位置。

## 边界

- 每行只有一块砖时，没有内部缝隙，答案为总行数；
- 多行缝隙完全对齐时，答案可能为 `0`；
- 不要把每行总宽度记录为候选，否则会错误选择墙体右边缘。

## 90 秒面试表达

竖线在某一行经过内部缝隙时就不会穿过砖，所以要找的是被最多行共享的缝隙横坐标。我对每行除最后一块外计算前缀和，用哈希表统计各坐标出现次数。若最多有 `g` 行在同一位置有缝隙，答案就是总行数减 `g`。时间和空间都与砖块总数成正比。

## 常见追问

- 为什么排除最后一块：那是墙体右边缘，题目禁止沿边缘画线；
- 每行只有一块砖时，哈希表为空，答案等于总行数；
- 前缀和代表的是位置，不能只统计砖块宽度。
