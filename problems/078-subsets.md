## 题目

给定一个元素互不相同的整数数组 `nums`，返回它的全部子集，也就是幂集。答案中不能出现重复子集，顺序不限。

### 示例

```text
输入：nums = [1, 2, 3]
输出：[[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
```

## 与全排列的区别

全排列要求每个叶子结点才是答案，而且下一层可以选择任意未使用元素。

子集问题中，搜索树上的每个结点都是答案。为了避免 `[1, 2]` 和 `[2, 1]` 表示同一子集，递归只从当前下标之后继续选择。

## Python 实现

```python
class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        answer: list[list[int]] = []
        path: list[int] = []

        def backtrack(start: int) -> None:
            answer.append(path.copy())

            for index in range(start, len(nums)):
                path.append(nums[index])
                backtrack(index + 1)
                path.pop()

        backtrack(0)
        return answer
```

## 为什么进入递归就记录

子集长度可以是 `0` 到 `n`。当前路径无论多长，都是一个合法子集，所以每到一个状态都要记录，而不是只在无法继续选择时记录。

初始空路径也会被记录，因此空集不会遗漏。

## 正确性说明

路径中的元素下标严格递增，所以每条路径都是合法子集，且同一组下标只会按唯一顺序出现，不会重复。任意子集都可以把元素下标按升序排列，算法会依次选择这些下标并到达对应路径，因此所有子集都会被生成。

## 复杂度

- 时间复杂度：`O(n · 2ⁿ)`，共有 `2ⁿ` 个子集，复制路径最坏需要 `O(n)`。
- 空间复杂度：`O(n)`，不计输出时为路径和递归栈。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---|---|
| `[0]` | `[[], [0]]` | 空集 |
| `[1, 2]` | 4 个子集 | 每个元素选或不选 |
| `[1, 2, 3]` | 8 个子集 | 幂集大小 |

## 90 秒面试表达

“子集可以用回溯枚举。与全排列不同，搜索树上的每个结点本身就是一个合法答案，所以进入递归就复制当前路径。参数 `start` 限制下一层只能选择后面的元素，让下标始终递增，从而避免同一子集以不同顺序重复出现。共有 `2^n` 个子集，复制答案后时间 `O(n·2^n)`，额外空间 `O(n)`。”

## 常见追问

- 也可以按每个元素“选或不选”构造二叉搜索树。
- 位掩码 `0` 到 `2ⁿ - 1` 也能枚举全部子集。
- 输入有重复元素时，应先排序并在同一层去重。
