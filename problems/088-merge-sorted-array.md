## 题目

给定两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，以及它们各自的有效元素数量 `m` 和 `n`。

`nums1` 的长度为 `m + n`，后面预留了 `n` 个位置。请把 `nums2` 合并到 `nums1` 中，使 `nums1` 最终仍按非递减顺序排列。结果必须直接写入 `nums1`。

### 示例

```text
输入：nums1 = [1,2,3,0,0,0], m = 3
      nums2 = [2,5,6], n = 3
操作后：nums1 = [1,2,2,3,5,6]
```

### 约束观察

- 两个数组已经有序，可以使用双指针。
- `nums1` 尾部有足够空位。
- 从前向后写入可能覆盖 `nums1` 中尚未比较的有效元素。
- 从后向前写入不会破坏未处理数据。

## 使用额外数组

最直观的方法是复制 `nums1` 的前 `m` 个元素，再从前向后归并两个数组。时间复杂度为 `O(m + n)`，但需要 `O(m)` 额外空间。

题目已经在 `nums1` 尾部预留空间，可以直接从最大元素开始填充。

## 优化抓手

三个指针分别指向：

- `first`：`nums1` 有效部分的最后一个元素；
- `second`：`nums2` 的最后一个元素；
- `write`：`nums1` 最后一个待写位置。

比较两个候选，把较大值写到 `write`，然后移动对应指针。

## Python 实现

```python
class Solution:
    def merge(
        self,
        nums1: list[int],
        m: int,
        nums2: list[int],
        n: int,
    ) -> None:
        first = m - 1
        second = n - 1
        write = m + n - 1

        # 从尾部写入，避免覆盖 nums1 中尚未比较的有效元素。
        while second >= 0:
            if first >= 0 and nums1[first] > nums2[second]:
                nums1[write] = nums1[first]
                first -= 1
            else:
                nums1[write] = nums2[second]
                second -= 1

            write -= 1
```

## 为什么只需要保证 `nums2` 处理完

如果 `nums2` 已经全部写入，`nums1` 剩余有效元素本来就在正确位置，无需移动。

如果 `nums1` 先处理完，循环仍会继续，把 `nums2` 剩余元素依次写到 `nums1` 前部。因此循环条件只需要是：

```python
while second >= 0:
```

## 相等时为什么写 `nums2`

当两个候选相等时，写哪一个都不会影响排序结果。代码选择写 `nums2`，可以让第二指针持续推进，并保持判断简洁。

## 正确性说明

每轮开始时，`write` 右侧已经放置了所有已处理元素中的最大值并保持有序。两个未处理数组的最大候选分别位于 `first` 和 `second`，选择较大者写入 `write`，因此新的后缀仍然正确。循环结束时 `nums2` 已全部写入，`nums1` 剩余元素位置无需改变，整个数组完成有序合并。

## 复杂度

- 时间复杂度：`O(m + n)`。每个有效元素最多处理一次。
- 空间复杂度：`O(1)`。直接使用 `nums1` 的预留空间。

## 边界用例

| `nums1, m` | `nums2, n` | 合并结果 | 检查点 |
|---|---|---|---|
| `[1,2,3,0,0,0], 3` | `[2,5,6], 3` | `[1,2,2,3,5,6]` | 基础路径 |
| `[1], 1` | `[], 0` | `[1]` | 第二数组为空 |
| `[0], 0` | `[1], 1` | `[1]` | 第一数组无有效元素 |
| `[4,5,6,0,0,0], 3` | `[1,2,3], 3` | `[1,2,3,4,5,6]` | 第二数组全部更小 |
| `[1,2,2,0,0], 3` | `[2,2], 2` | `[1,2,2,2,2]` | 重复值 |

## 90 秒面试表达

“两个数组有序，常规归并可以做到 `O(m + n)`，但从前向后写会覆盖 `nums1` 中尚未处理的元素。我利用尾部预留空间，从后向前写。两个读指针分别指向有效部分末尾，写指针指向整个 `nums1` 末尾，每次把较大候选写入。只要 `nums2` 还没处理完就继续；如果它先结束，`nums1` 剩余元素已经在正确位置。时间 `O(m + n)`、空间 `O(1)`。”

## 常见追问

- 如果不能修改输入，可以创建结果数组并从前向后归并。
- 如果两个数组都没有预留空间，原地合并通常需要更复杂的块算法或牺牲时间复杂度。
- 合并多个有序数组可以使用最小堆，时间复杂度为 `O(N log k)`。
