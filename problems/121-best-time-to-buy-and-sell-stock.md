## 题目

给定数组 `prices`，`prices[i]` 表示第 `i` 天的股票价格。

最多只能完成一笔交易：先在某一天买入，再在之后某一天卖出。返回能够获得的最大利润；如果无法盈利，返回 `0`。

### 示例

```text
输入：prices = [7, 1, 5, 3, 6, 4]
输出：5
解释：第 2 天以 1 买入，第 5 天以 6 卖出
```

```text
输入：prices = [7, 6, 4, 3, 1]
输出：0
```

## 暴力方案

枚举买入日和它之后的卖出日，计算所有价差，时间复杂度为 `O(n²)`。

重复计算来自同一卖出日之前的最低价格。扫描到当天时，只需要知道：

- 此前出现过的最低价格；
- 如果今天卖出，能获得多少利润。

## Python 实现

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        minimum_price = prices[0]
        maximum_profit = 0

        for price in prices[1:]:
            maximum_profit = max(
                maximum_profit,
                price - minimum_price,
            )
            minimum_price = min(minimum_price, price)

        return maximum_profit
```

## 为什么先算利润再更新最低价

交易要求先买后卖。处理当天价格时，先用此前最低价计算“今天卖出”的利润，再把今天纳入后续日期可用的买入候选，语义最清晰。

即使先更新再计算，本题也只会多考虑当天买当天卖的零利润，不影响答案；但面试中建议保持状态定义严格。

## 正确性说明

遍历到第 `i` 天时，`minimum_price` 是第 `i` 天之前的最低价格。因此 `prices[i] - minimum_price` 是以第 `i` 天作为卖出日的最大利润。算法比较所有可能卖出日的最优利润，所以不会漏掉全局最优交易；初始化为零保证价格持续下跌时不进行交易。

## 复杂度

- 时间复杂度：`O(n)`，数组只扫描一次。
- 空间复杂度：`O(1)`。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `[7,1,5,3,6,4]` | `5` | 基础路径 |
| `[7,6,4,3,1]` | `0` | 不交易 |
| `[1]` | `0` | 单日 |
| `[1,2]` | `1` | 最短盈利 |
| `[2,2,2]` | `0` | 价格不变 |

## 90 秒面试表达

“暴力枚举买卖日期是 `O(n²)`。扫描到某一天时，如果今天卖出，最优买入价一定是此前最低价，所以我维护 `minimum_price`，用当前价格减它更新最大利润，再把当前价格纳入后续最低价。这样覆盖了每个卖出日的最优交易，时间 `O(n)`、空间 `O(1)`；价格一直下降时保持答案为零。”

## 常见追问

- 返回交易日期时，在最低价更新时记录买入下标，在利润更新时保存买卖下标。
- 允许多次交易时，问题变为第 122 题，可以累加全部相邻正收益。
- 限制最多 `k` 次交易时，通常使用状态机动态规划。
