## 题目

给定非负整数 `x`，返回它的算术平方根向下取整后的整数。

不能使用内置指数函数或幂运算。

### 示例

```text
输入：x = 4
输出：2

输入：x = 8
输出：2
解释：sqrt(8) 约为 2.828，向下取整为 2
```

## 在答案空间二分

要寻找最大的整数 `value`，满足：

```text
value² <= x
```

这个判断具有单调性：

- 小于等于真实答案的值都满足；
- 大于真实答案的值都不满足。

因此可以在候选答案区间上二分，并记录最后一个满足条件的值。

## Python 实现

```python
class Solution:
    def mySqrt(self, x: int) -> int:
        if x < 2:
            return x

        left = 1
        right = x // 2
        answer = 1

        # 在闭区间中二分，并记录所有平方不超过 x 的候选答案。
        while left <= right:
            middle = left + (right - left) // 2

            if middle * middle <= x:
                answer = middle
                left = middle + 1
            else:
                right = middle - 1

        return answer
```

## 为什么上界可以取 `x // 2`

当 `x >= 2` 时，平方根不会超过 `x / 2`。`x = 2` 和 `x = 3` 时上界为 1，也包含正确答案。

`0` 和 `1` 单独返回，避免候选区间为空。

在固定宽度整数语言中，`middle * middle` 可能溢出，可改用 `middle <= x // middle`；Python 整数不会溢出。

## 正确性说明

搜索过程中，`answer` 始终是已经检查过且平方不超过 `x` 的最大候选。若中点满足条件，中点及其左侧都可行，记录中点并向右寻找更大答案；否则中点及其右侧都不可行，向左收缩。循环结束后不存在更大的可行整数，因此 `answer` 正是平方根向下取整值。

## 复杂度

- 时间复杂度：`O(log x)`。
- 空间复杂度：`O(1)`。

## 边界用例

| 输入 | 预期 | 检查点 |
|---:|---:|---|
| `0` | `0` | 特殊值 |
| `1` | `1` | 特殊值 |
| `4` | `2` | 完全平方数 |
| `8` | `2` | 向下取整 |
| `2147395599` | `46339` | 大整数 |

## 90 秒面试表达

“把问题转成寻找最大的整数 `v`，使 `v² <= x`。这个谓词在答案空间中先真后假，可以二分。中点满足就记录为当前答案并向右找更大值，否则向左收缩。0 和 1 直接返回，其他数的上界可取 `x//2`。时间 `O(log x)`、空间 `O(1)`。”

## 常见追问

- 固定宽度整数要用除法比较避免乘法溢出。
- 求带精度的浮点平方根时，可二分到区间足够小。
- 牛顿迭代通常收敛更快，也能求整数平方根。
