## 题目

有 `n` 个孩子站成一排，数组 `ratings[i]` 表示第 `i` 个孩子的评分。

给每个孩子至少一颗糖；如果一个孩子的评分高于相邻孩子，他获得的糖也必须更多。返回满足条件所需的最少糖果总数。

本页难度按提供的面试题截图记录。

### 示例

```text
输入：ratings = [1, 0, 2]
输出：5
解释：可以分配 [2, 1, 2]
```

```text
输入：ratings = [1, 2, 2]
输出：4
解释：可以分配 [1, 2, 1]
```

## 为什么要从两个方向看

每个孩子可能同时受到左右两个约束：

- 从左向右扫描，保证评分高于左邻居时糖更多；
- 从右向左扫描，保证评分高于右邻居时糖更多。

第一次扫描得到满足左侧约束的最小分配。第二次扫描时，当前糖果数取原值与“右邻居糖果数加一”的最大值，同时满足两侧约束。

## Python 实现

```python
class Solution:
    def candy(self, ratings: list[int]) -> int:
        candies = [1] * len(ratings)

        # 正向保证比左邻评分高的孩子糖果更多。
        for index in range(1, len(ratings)):
            if ratings[index] > ratings[index - 1]:
                candies[index] = candies[index - 1] + 1

        # 反向补齐右邻约束，取 max 保留已满足的左侧约束。
        for index in range(len(ratings) - 2, -1, -1):
            if ratings[index] > ratings[index + 1]:
                candies[index] = max(
                    candies[index],
                    candies[index + 1] + 1,
                )

        return sum(candies)
```

## 为什么第二遍取最大值

第一遍已经建立了左侧约束。第二遍若直接覆盖，可能为了满足右侧而破坏左侧关系。

取最大值意味着只在右侧约束要求更多糖时增加，不减少第一遍已经确定的必要糖果。

评分相等的相邻孩子之间没有大小约束，因此不需要给相同糖果，也不需要递增。

## 正确性说明

左向扫描后，每个评分高于左邻居的孩子都恰好多拿一颗，得到满足所有左侧约束的最小值。右向扫描对评分高于右邻居的孩子施加同样的最小下界，并与已有值取最大，因此最终满足两侧全部约束。每个位置取的是左右约束下界的最大值，任何合法方案都不能给得更少，所以总糖果数最小。

## 复杂度

- 时间复杂度：`O(n)`，两次扫描加一次求和。
- 空间复杂度：`O(n)`，糖果数组。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `[1]` | `1` | 单个孩子 |
| `[1,0,2]` | `5` | 两侧都更高 |
| `[1,2,2]` | `4` | 相等评分 |
| `[1,2,3,4]` | `10` | 连续上升 |
| `[4,3,2,1]` | `10` | 连续下降 |

## 90 秒面试表达

“每个位置同时可能受左邻居和右邻居约束，单向扫描不够。我先把糖果都设为 1，从左到右处理评分高于左邻居的情况；再从右到左处理评分高于右邻居的情况，糖果数取当前值和右邻居加一的最大值，避免破坏第一遍约束。每个位置最终取左右下界的最大值，因此满足条件且最小。时间、空间都是 `O(n)`。”

## 常见追问

- 可以分析上升、下降坡度，把额外空间优化到 `O(1)`。
- 如果孩子围成一圈，需要额外处理首尾相邻关系。
- 若比较规则变为评分相等也必须糖果相等，约束模型会改变。
