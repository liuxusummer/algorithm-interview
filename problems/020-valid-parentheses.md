## 题目

给定只包含 `()`、`[]`、`{}` 的字符串 `s`，判断括号是否有效。

有效字符串需要同时满足：

- 每个左括号都由相同类型的右括号闭合；
- 括号必须按正确顺序闭合；
- 不能出现没有对应左括号的右括号。

### 示例

```text
输入：s = "()[]{}"
输出：True

输入：s = "([)]"
输出：False
```

## 为什么需要栈

遇到右括号时，它必须匹配“最近一个尚未闭合的左括号”。这种后出现、先匹配的顺序正是后进先出，因此用栈保存左括号。

为了减少分支，可以建立“右括号 → 左括号”的映射。字符不在映射中就是左括号，直接入栈；否则检查栈顶。

## Python 实现

```python
class Solution:
    def isValid(self, s: str) -> bool:
        matching = {
            ")": "(",
            "]": "[",
            "}": "{",
        }
        stack: list[str] = []

        # 栈只保存尚未匹配的左括号，遇到右括号立即核对栈顶。
        for char in s:
            if char not in matching:
                stack.append(char)
                continue

            if not stack or stack.pop() != matching[char]:
                return False

        return not stack
```

## 两个容易漏掉的条件

- 右括号出现时栈可能为空，例如 `")"`；
- 扫描结束后栈必须为空，例如 `"((("` 虽然从未失配，但仍有括号未闭合。

## 正确性说明

栈始终保存扫描前缀中尚未匹配的左括号，并按出现顺序排列。遇到右括号时，合法嵌套要求它必须匹配栈顶；不匹配或栈为空即可判错。扫描结束后栈为空，说明所有左括号都被正确闭合。因此算法返回真当且仅当整个字符串有效。

## 复杂度

- 时间复杂度：`O(n)`，每个字符至多入栈、出栈一次。
- 空间复杂度：`O(n)`，全为左括号时栈达到最大。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---|---|
| `"()"` | `True` | 基础匹配 |
| `"()[]{}"` | `True` | 多种括号 |
| `"(]"` | `False` | 类型不匹配 |
| `"([)]"` | `False` | 顺序不匹配 |
| `"((("` | `False` | 扫描结束栈非空 |

## 90 秒面试表达

“右括号必须匹配最近一个未闭合的左括号，所以使用栈。扫描时左括号入栈；遇到右括号就检查栈是否非空且栈顶类型匹配，否则立即返回假。最后还要确认栈为空，避免遗漏未闭合的左括号。每个字符最多进出栈一次，时间 `O(n)`、空间 `O(n)`。”

## 常见追问

- 如果还包含普通字符，可以明确是忽略它们还是视为非法输入。
- 如果只需要一种括号，可用计数器，但多种括号必须保存嵌套顺序。
- 若要报告第一个错误位置，可在栈中同时保存下标。
