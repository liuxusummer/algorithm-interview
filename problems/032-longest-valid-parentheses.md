## 题目

给定只包含 `(` 和 `)` 的字符串 `s`，返回其中最长有效括号连续子串的长度。

本页难度按提供的面试题截图记录。

### 示例

```text
输入：s = "(()"
输出：2

输入：s = ")()())"
输出：4
解释：最长有效子串是 "()()"
```

## 解法一：索引栈

### 为什么栈里存下标

这题不只需要判断是否匹配，还要计算连续区间长度，因此栈中保存下标。

栈底保存“当前有效区间左侧最近的无效位置”。先放入哨兵 `-1`：

- 遇到 `(`：把下标入栈；
- 遇到 `)`：先弹栈；
- 弹完栈为空，说明当前右括号无法匹配，把它作为新的边界；
- 栈非空时，当前有效长度是 `index - stack[-1]`。

### Python 实现

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        # -1 是第一段合法括号前的虚拟边界。
        stack = [-1]
        longest = 0

        for index, char in enumerate(s):
            if char == "(":
                stack.append(index)
                continue

            stack.pop()

            if not stack:
                # 当前右括号无法匹配，它会成为下一段合法区间的边界。
                stack.append(index)
            else:
                longest = max(longest, index - stack[-1])

        return longest
```

### 哨兵 `-1` 的作用

对于从下标 `0` 开始的合法子串，例如 `"()"`，处理到下标 `1` 时栈中只剩 `-1`，长度就是 `1 - (-1) = 2`。

当出现无法匹配的右括号时，用它的下标替换哨兵。后续合法区间只能从它右侧开始。

### 正确性说明

栈顶始终是当前下标左侧、不能被纳入当前有效后缀的最近边界：它可能是未匹配左括号，也可能是无效右括号。匹配一个右括号后，若栈非空，则边界后一位到当前下标构成有效后缀，其长度为两下标之差；若栈为空，当前右括号成为新边界。逐位置取最大值即可得到最长有效连续子串。

### 复杂度

- 时间复杂度：`O(n)`，每个下标最多入栈、出栈一次。
- 空间复杂度：`O(n)`，最坏保存全部左括号下标。

## 解法二：正反两次计数扫描

如果只需要最长长度，不需要恢复括号的配对关系，可以只维护左右括号数量：

- 从左向右扫描，右括号比左括号多时，当前前缀不可能再成为合法区间，计数清零；
- 左右括号数量相等时，当前扫描段是一个合法括号后缀，用总括号数更新答案；
- 但单向扫描无法处理多余左括号，例如 `"(()"`，所以还要从右向左对称扫描一次。

反向扫描时规则对称：左括号比右括号多，说明右侧边界不足，计数清零。

### Python 实现

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        longest = 0
        left_count = 0
        right_count = 0

        # 正向扫描负责排除“右括号过多”的无效前缀。
        for char in s:
            if char == "(":
                left_count += 1
            else:
                right_count += 1

            if left_count == right_count:
                longest = max(longest, 2 * right_count)
            elif right_count > left_count:
                left_count = 0
                right_count = 0

        left_count = 0
        right_count = 0

        # 反向扫描补上“左括号过多”的情况，例如 "(()"。
        for char in reversed(s):
            if char == "(":
                left_count += 1
            else:
                right_count += 1

            if left_count == right_count:
                longest = max(longest, 2 * left_count)
            elif left_count > right_count:
                left_count = 0
                right_count = 0

        return longest
```

### 为什么必须扫描两个方向

正向扫描遇到右括号过多时，可以确定这个右括号无法被未来的左括号补救，因此能安全重置。但左括号过多时，未来仍可能出现右括号，不能立即重置。

反向扫描恰好交换了两类括号的角色：它能安全排除左括号过多的区间。两个方向合起来覆盖所有合法连续子串。

### 正确性说明

在一次未重置的正向扫描段中，只要左右计数相等，从最近一次无效右括号之后到当前位置就是合法括号串；右括号超过左括号时，任何跨过当前位置的区间都无法合法，因此重置不会丢失答案。该方向会找到所有不含多余左括号的最优区间。

反向扫描对称地找到所有可能含有多余左括号、但右侧存在完整合法后缀的区间。因此两次扫描取最大值就是全局最长有效括号长度。

### 复杂度

- 时间复杂度：`O(n)`，字符串正向、反向各扫描一次。
- 空间复杂度：`O(1)`，只维护四个计数变量。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `""` | `0` | 空字符串 |
| `"((("` | `0` | 没有闭合 |
| `")))"` | `0` | 边界持续更新 |
| `"()"` | `2` | 哨兵 |
| `")()())"` | `4` | 多段合法区间 |

## 常见追问

- 动态规划也能在线性时间求解，`dp[i]` 表示以 `i` 结尾的最长有效长度。
- 索引栈更容易恢复具体子串；双向计数只适合求最大长度。
- 若要返回子串本身，同时记录最大长度对应的结束下标。
