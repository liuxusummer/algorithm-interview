## 题目

给定只包含 `(` 和 `)` 的字符串 `s`，返回其中最长有效括号连续子串的长度。

本页难度按提供的面试题截图记录。

### 示例

```text
输入：s = "(()"
输出：2

输入：s = ")()())"
输出：4
解释：最长有效子串是 "()()"
```

## 为什么栈里存下标

这题不只需要判断是否匹配，还要计算连续区间长度，因此栈中保存下标。

栈底保存“当前有效区间左侧最近的无效位置”。先放入哨兵 `-1`：

- 遇到 `(`：把下标入栈；
- 遇到 `)`：先弹栈；
- 弹完栈为空，说明当前右括号无法匹配，把它作为新的边界；
- 栈非空时，当前有效长度是 `index - stack[-1]`。

## Python 实现

```python
class Solution:
    def longestValidParentheses(self, s: str) -> int:
        # -1 是第一段合法括号前的虚拟边界。
        stack = [-1]
        longest = 0

        for index, char in enumerate(s):
            if char == "(":
                stack.append(index)
                continue

            stack.pop()

            if not stack:
                # 当前右括号无法匹配，它会成为下一段合法区间的边界。
                stack.append(index)
            else:
                longest = max(longest, index - stack[-1])

        return longest
```

## 哨兵 `-1` 的作用

对于从下标 `0` 开始的合法子串，例如 `"()"`，处理到下标 `1` 时栈中只剩 `-1`，长度就是 `1 - (-1) = 2`。

当出现无法匹配的右括号时，用它的下标替换哨兵。后续合法区间只能从它右侧开始。

## 正确性说明

栈顶始终是当前下标左侧、不能被纳入当前有效后缀的最近边界：它可能是未匹配左括号，也可能是无效右括号。匹配一个右括号后，若栈非空，则边界后一位到当前下标构成有效后缀，其长度为两下标之差；若栈为空，当前右括号成为新边界。逐位置取最大值即可得到最长有效连续子串。

## 复杂度

- 时间复杂度：`O(n)`，每个下标最多入栈、出栈一次。
- 空间复杂度：`O(n)`，最坏保存全部左括号下标。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `""` | `0` | 空字符串 |
| `"((("` | `0` | 没有闭合 |
| `")))"` | `0` | 边界持续更新 |
| `"()"` | `2` | 哨兵 |
| `")()())"` | `4` | 多段合法区间 |

## 90 秒面试表达

“为了计算连续长度，栈中存下标，并先放哨兵 `-1` 代表有效区间左侧边界。左括号下标入栈；右括号先弹出一个位置，若栈空说明它无法匹配，就把当前下标作为新边界，否则当前有效后缀长度是当前下标减栈顶。遍历时更新最大值。每个下标最多进出栈一次，时间 `O(n)`、空间 `O(n)`。”

## 常见追问

- 动态规划也能在线性时间求解，`dp[i]` 表示以 `i` 结尾的最长有效长度。
- 正反两次计数扫描可以把额外空间降到 `O(1)`。
- 若要返回子串本身，同时记录最大长度对应的结束下标。
