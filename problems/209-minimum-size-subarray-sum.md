## 题目

给定一个由正整数组成的数组 `nums` 和一个正整数 `target`，找出总和大于或等于 `target` 的最短连续子数组，并返回它的长度。

如果不存在满足条件的子数组，返回 `0`。

### 示例

```text
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 的长度最短
```

### 约束观察

- 数组元素全部为正数，这是滑动窗口成立的关键条件。
- 右边界右移时窗口和只会增大。
- 左边界右移时窗口和只会减小。
- 题目要求最短长度，所以窗口满足条件后要尽可能收缩。

## 先说暴力解

枚举每个起点，向右累加直到总和达到 `target`，记录当前长度后处理下一个起点。

最坏情况下，每个起点都要扫描到末尾，时间复杂度为 `O(n²)`。

## 优化抓手

维护窗口 `[left, right]` 和窗口元素总和：

1. 右边界加入新元素，让窗口和增长；
2. 当窗口和达到 `target` 时，记录长度；
3. 持续移动左边界并减去离开窗口的元素，寻找以当前右边界结尾的最短合法窗口。

因为所有元素都是正数，一旦窗口和不足，继续收缩只会更小，所以必须移动右边界；一旦满足条件，就可以安全收缩。

## Python 实现

```python
from typing import List


class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:

        left = 0
        window_sum = 0
        ans = float("inf")

        for right in range(len(nums)):
            # 将 nums[right] 加入窗口
            window_sum += nums[right]

            # 当前窗口满足条件，尝试缩小窗口
            while window_sum >= target:
                ans = min(ans, right - left + 1)

                window_sum -= nums[left]
                left += 1

        return 0 if ans == float("inf") else ans
```

`ans` 初始化为正无穷，表示当前还没有找到合法窗口。扫描结束后如果它仍未改变，就按题意返回 `0`。

## 为什么这里能用滑动窗口

滑动窗口需要窗口状态随边界移动具有单调性。本题所有元素都是正数：

- 扩大窗口不会让总和变小；
- 缩小窗口不会让总和变大。

如果数组允许负数，这两个性质都会失效。此时不能直接使用相同窗口逻辑，需要考虑前缀和与单调队列。

## 正确性说明

对每个右边界，算法先加入当前元素，然后在窗口和满足条件时不断移动左边界。循环结束前记录了所有以该右边界结尾的合法窗口，并保留其中最短的一个；循环结束后再收缩会导致窗口和不足，因此没有遗漏更短合法窗口。遍历所有右边界后，全局最小值就是答案。

## 复杂度

- 时间复杂度：`O(n)`。每个元素最多被右边界加入一次、被左边界移出一次。
- 空间复杂度：`O(1)`。

## 边界用例

| `target` | 输入 | 预期 | 检查点 |
|---:|---|---:|---|
| 7 | `[2,3,1,2,4,3]` | 2 | 基础路径 |
| 4 | `[1,4,4]` | 1 | 单元素满足 |
| 11 | `[1,1,1,1,1,1,1,1]` | 0 | 无解 |
| 5 | `[5]` | 1 | 单元素数组 |
| 1 | `[]` | 0 | 空数组 |

## 90 秒面试表达

“暴力解从每个起点向右累加，最坏是 `O(n²)`。因为数组元素全部为正，扩大窗口时总和单调增加，缩小窗口时总和单调减少，所以可以使用滑动窗口。右边界每加入一个数，只要窗口和大于等于目标，就记录长度并持续移动左边界，找到以当前右端点结尾的最短合法窗口。每个元素最多进出窗口一次，时间 `O(n)`、空间 `O(1)`。”

## 常见追问

- 如果数组含负数，需要使用前缀和与单调队列解决更一般的最短子数组问题。
- 如果要求子数组和恰好等于目标，正整数条件下仍可用窗口，但收缩与计数规则需要调整。
- 如果要返回区间下标，在更新最短长度时同步保存 `left` 和 `right`。
