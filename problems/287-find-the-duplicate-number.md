## 题目

给定包含 `n + 1` 个整数的数组 `nums`，每个整数都位于 `[1, n]`。数组中只有一个重复数字，但它可能出现多次，返回这个重复数。

要求不修改数组，并且只使用常数级额外空间。

### 示例

```text
输入：nums = [1, 3, 4, 2, 2]
输出：2

输入：nums = [3, 1, 3, 4, 2]
输出：3
```

## 把数组看成链表

把数组下标看成结点，并定义下一跳：

```text
next(index) = nums[index]
```

数组值都在 `[1, n]`，所以从下标 `0` 出发会一直落在合法下标中。由于结点数量有限，路径最终必然进入环。

重复数字意味着至少两个下标指向同一个值。这个值正是从下标 `0` 出发所进入环的入口。

## Floyd 两阶段判圈

1. 慢指针每次走一步，快指针每次走两步，二者一定在环内相遇；
2. 一个指针回到起点，两个指针都改为每次走一步；
3. 再次相遇的位置就是环入口，也就是重复数字。

## Python 实现

```python
class Solution:
    def findDuplicate(self, nums: list[int]) -> int:
        slow = nums[0]
        fast = nums[0]

        # 把 nums[i] 看作 next 指针，重复值对应链表环入口。
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]

            if slow == fast:
                break

        finder = nums[0]

        # 从起点与相遇点同步前进，交点就是重复值。
        while finder != slow:
            finder = nums[finder]
            slow = nums[slow]

        return finder
```

## 为什么第二阶段会在入口相遇

设起点到环入口的距离为 `a`，入口到第一次相遇点的距离为 `b`，环长为 `c`。

相遇时快指针走过的距离是慢指针的两倍，因此可以推出：

```text
a = 若干个完整环长 - b
```

让一个指针从起点、另一个从相遇点同时每次走一步，前者走 `a` 步到入口，后者走完剩余环段并绕若干圈后也到入口。

## 正确性说明

由抽屉原理，从下标 `0` 沿数组值跳转形成的函数图必然含环；唯一重复值是两个不同路径首次汇入的位置，因此对应环入口。Floyd 第一阶段保证找到环内相遇点，第二阶段利用起点到入口与相遇点到入口的距离关系找到入口。返回的环入口值即唯一重复数字。

## 复杂度

- 时间复杂度：`O(n)`，两个阶段的指针移动次数均为线性。
- 空间复杂度：`O(1)`。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `[1,1]` | `1` | 最小数组 |
| `[1,3,4,2,2]` | `2` | 重复两次 |
| `[3,1,3,4,2]` | `3` | 环入口靠前 |
| `[2,2,2,2,2]` | `2` | 重复多次 |

## 90 秒面试表达

“把下标看作结点，`nums[index]` 看作下一跳，就得到一个函数图。因为有 `n+1` 个位置、值只有 `1..n`，路径必然进环；重复值对应多个下标指向同一结点，也就是环入口。先用 Floyd 快慢指针在环内相遇，再让一个指针回到 `nums[0]`，两者同速前进，再次相遇处就是入口。时间 `O(n)`、空间 `O(1)`，且不修改数组。”

## 常见追问

- 使用集合也能解决，但空间为 `O(n)`。
- 排序后扫描会修改数组或需要复制，时间为 `O(n log n)`。
- 按值域做二分计数可达 `O(n log n)` 时间、`O(1)` 空间，同样不修改数组。
