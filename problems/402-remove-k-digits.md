## 题目

给定非负整数字符串 `num` 和整数 `k`，删除恰好 `k` 位数字，使剩余数字最小。返回不含多余前导零的字符串；如果所有数字都被删除，返回 `"0"`。

### 示例

```text
输入：num = "1432219", k = 3
输出："1219"
```

```text
输入：num = "10200", k = 1
输出："200"
```

```text
输入：num = "10", k = 2
输出："0"
```

## 贪心选择

同样长度的数字，越靠左的数位影响越大。当当前数字小于前一个已保留数字时，删除前面的较大数字一定能让结果更小。

维护单调不下降栈：

- 当前数字比栈顶小且还有删除次数时，持续弹出栈顶；
- 当前数字随后入栈；
- 如果扫描结束仍有删除次数，说明数字整体不下降，应从末尾删除最大的低权位数字。

## Python 实现

```python
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        stack: list[str] = []

        for digit in num:
            while k > 0 and stack and stack[-1] > digit:
                stack.pop()
                k -= 1

            stack.append(digit)

        if k > 0:
            del stack[-k:]

        result = "".join(stack).lstrip("0")
        return result or "0"
```

## 为什么出现下降就删前一个

设相邻数字为 `a > b`。保留 `a`、删除 `b` 会让较大的 `a` 留在更高位；删除 `a`、让较小的 `b` 前移，一定得到更小结果。

因此在删除次数允许时，逆序对左侧的较大数字应优先删除。单调栈正好维护“此前还可能被当前更小数字淘汰”的候选。

## 为什么剩余次数从末尾删

如果扫描完成后仍有删除次数，栈中数字单调不下降。此时不存在能让更小数字前移的逆序对，删除越靠后的数字对高位影响越小；从末尾删除即可得到最小结果。

## 正确性说明

当栈顶大于当前数字时，任何保留栈顶而删除当前数字的方案，都可以交换为删除栈顶、保留当前数字，并在更高位首次产生更小数位，所以后者严格更优。算法持续执行这一安全交换，直到栈单调或次数耗尽。若仍需删除，单调序列中删除末尾对高位影响最小。最终恰好删除 `k` 位并获得最小数。

## 复杂度

- 时间复杂度：`O(n)`，每个数字最多入栈、出栈一次。
- 空间复杂度：`O(n)`。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---|---|
| `"1432219", 3` | `"1219"` | 多次弹栈 |
| `"10200", 1` | `"200"` | 去前导零 |
| `"10", 2` | `"0"` | 全部删除 |
| `"12345", 2` | `"123"` | 从末尾删除 |
| `"1111", 2` | `"11"` | 相同数字 |

## 90 秒面试表达

“同长度数字先比较高位，所以当当前数字比前一个保留数字小时，应优先删掉前面的较大数字，让小数字前移。我用单调不下降栈，只要还有删除次数且栈顶更大就弹栈。若遍历后次数没用完，说明序列整体不下降，从末尾删即可。最后去掉前导零，空结果返回 0。每个数字最多进出栈一次，时间 `O(n)`、空间 `O(n)`。”

## 常见追问

- 如果要求删除至多 `k` 位，非负整数场景下删除更多位通常更小，但要先明确是否允许空结果。
- 如果输入很大，可以流式维护栈，但输出前仍需处理剩余删除次数。
- 这类题的核心是“高位优先”，常见于构造最小字典序序列。
