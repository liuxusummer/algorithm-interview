## 题目

已知 API `rand7()` 会等概率返回 `1` 到 `7` 的整数。只能调用这个 API，实现 `rand10()`，使其等概率返回 `1` 到 `10`。

不能直接调用其他随机函数。

## 先构造 49 个等概率状态

独立调用两次 `rand7()`：

```text
row = rand7() - 1      # 0..6
column = rand7()       # 1..7
value = row * 7 + column
```

`value` 等概率分布在 `1..49`，因为每个值都唯一对应一组有序调用结果。

10 不能整除 49。如果直接对 49 个状态取模，部分结果会出现 5 次，部分只出现 4 次，分布不均匀。

## 拒绝采样

只接受 `1..40`：

- 40 个状态可以平均分成 10 组；
- 每个输出值恰好对应 4 个输入状态；
- `41..49` 被拒绝，重新采样。

## Python 实现

```python
# rand7() 由题目环境提供。


class Solution:
    def rand10(self) -> int:
        while True:
            # 两次 rand7 等概率生成 1～49，只接受可被 10 均分的前 40 个值。
            value = (rand7() - 1) * 7 + rand7()

            if value <= 40:
                return 1 + (value - 1) % 10
```

## 为什么输出严格均匀

条件在“采样落入 `1..40`”时，每个被接受的 `value` 仍然等概率。

映射：

```text
1, 11, 21, 31  → 1
2, 12, 22, 32  → 2
...
10, 20, 30, 40 → 10
```

每个结果都对应 4 个等概率状态，因此返回概率都是 `4 / 40 = 1 / 10`。

拒绝只会让本轮重新开始，不会偏向任何输出。

## 期望复杂度

单轮被接受的概率为：

```text
40 / 49
```

直到成功所需轮数服从几何分布，期望轮数是 `49 / 40`；每轮调用两次 `rand7()`，期望调用次数为：

```text
2 × 49 / 40 = 2.45
```

- 期望时间复杂度：`O(1)`。
- 空间复杂度：`O(1)`。
- 理论最坏调用次数无上界，但持续拒绝的概率会指数下降。

## 边界检查

| `value` | 处理 | 输出 |
|---:|---|---:|
| `1` | 接受 | `1` |
| `10` | 接受 | `10` |
| `11` | 接受 | `1` |
| `40` | 接受 | `10` |
| `41..49` | 拒绝 | 重新采样 |

## 90 秒面试表达

“两次独立的 Rand7 可以构造 49 个等概率状态：`(a-1)*7+b`，范围是 1 到 49。因为 49 不能被 10 整除，直接取模会有偏差。我只接受 1 到 40，再按 `(value-1)%10+1` 映射，每个输出恰好对应 4 个等概率状态；41 到 49 重新采样。单轮成功率是 `40/49`，期望调用 Rand7 2.45 次，所以期望时间 `O(1)`。”

## 常见追问

- 可以继续利用被拒绝的 9 个状态构造更多随机位，降低期望调用次数。
- 从 `RandM` 生成 `RandN` 的通用方法是先构造足够大的等概率状态空间，再截取能被 `N` 整除的部分。
- 概率算法需要区分期望复杂度和最坏复杂度。
