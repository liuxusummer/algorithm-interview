## 题目

给定整数数组 `nums` 和窗口大小 `k`。窗口从数组最左侧开始，每次向右移动一位，请返回每个窗口中的最大值。

### 示例

```text
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
```

### 约束观察

- 窗口移动后，大部分元素仍然保留，重复扫描会浪费信息。
- 需要快速删除过期元素，也需要快速得到当前最大值。
- 最大值候选不仅要记录数值，还要记录下标以判断是否离开窗口。

## 先说暴力解

对每个长度为 `k` 的窗口调用 `max`，每次扫描 `k` 个元素。

共有约 `n - k + 1` 个窗口，时间复杂度为 `O(nk)`。

使用最大堆可以做到 `O(n log n)`，但清理已经离开窗口的元素需要延迟删除。单调队列可以进一步做到线性时间。

## 优化抓手

双端队列中保存元素下标，并让对应数值从队首到队尾单调递减：

- 队首始终是当前窗口最大值的下标；
- 新元素进入前，删除队尾所有不大于它的元素；
- 每轮删除已经落在窗口左侧的队首下标。

较小且更早的元素不可能再成为最大值，因为新元素更大、离开窗口还更晚。

## Python 实现

```python
from collections import deque


class Solution:
    def maxSlidingWindow(
        self,
        nums: list[int],
        k: int,
    ) -> list[int]:
        # 队列保存下标，队首始终是当前窗口最大值。
        candidates = deque()
        maximums: list[int] = []

        for right, value in enumerate(nums):
            # 先移除窗口外下标，再删除不可能成为最大值的较小候选。
            while candidates and candidates[0] <= right - k:
                candidates.popleft()

            while candidates and nums[candidates[-1]] <= value:
                candidates.pop()

            candidates.append(right)

            if right >= k - 1:
                maximums.append(nums[candidates[0]])

        return maximums
```

## 为什么队列保存下标

只保存数值无法区分相同元素，也无法判断队首元素是否已经离开窗口。保存下标后：

```text
candidates[0] <= right - k
```

就说明队首已经不属于当前窗口。

## 为什么可以删除队尾较小元素

假设旧元素比新元素小。只要旧元素仍在窗口，新元素也一定在窗口，因为新元素位置更靠右；此时旧元素不可能成为最大值。旧元素还会比新元素更早过期，因此可以永久删除。

相同数值时保留更新的下标也更有利，所以代码使用 `<=` 删除队尾。

## 正确性说明

队列始终只包含当前窗口内的下标，并按对应数值单调递减，因此队首是窗口最大值。删除队尾元素只移除了被更新、更大元素完全支配的候选，不会删除未来答案；删除队首只发生在它已经过期时。每个完整窗口记录一次队首，得到全部正确最大值。

## 复杂度

- 时间复杂度：`O(n)`。每个下标最多入队一次、出队一次。
- 空间复杂度：`O(k)`。队列最多保存一个窗口中的候选。

## 边界用例

| 输入 | `k` | 预期 | 检查点 |
|---|---:|---|---|
| `[1,3,-1,-3,5,3,6,7]` | 3 | `[3,3,5,5,6,7]` | 基础路径 |
| `[1]` | 1 | `[1]` | 单元素 |
| `[1,-1]` | 1 | `[1,-1]` | 窗口长度 1 |
| `[9,8,7,6]` | 4 | `[9]` | 整个数组一个窗口 |
| `[2,2,2]` | 2 | `[2,2]` | 重复最大值 |

“暴力方法对每个窗口扫描 `k` 个元素，时间是 `O(nk)`。我用双端队列保存最大值候选的下标，并让对应数值单调递减。每轮先删除已经离开窗口的队首，再删除所有不大于当前值的队尾，因为这些旧元素更小且更早过期，不可能再成为最大值。队首始终是当前窗口最大值。每个下标最多入队、出队一次，所以时间 `O(n)`、空间 `O(k)`。”

## 常见追问

- 窗口最小值只需把队列改为单调递增。
- 如果窗口大小动态变化，需要重新定义过期规则和候选维护方式。
- 如果数据以流式到达，保留队列与当前下标即可在线输出结果。
