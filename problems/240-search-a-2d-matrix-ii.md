## 题目

给定一个 `m × n` 的整数矩阵 `matrix`，矩阵具有以下性质：

- 每一行从左到右非递减；
- 每一列从上到下非递减。

判断目标值 `target` 是否存在于矩阵中。

### 示例

```text
输入：
matrix = [
  [ 1, 4, 7,11,15],
  [ 2, 5, 8,12,19],
  [ 3, 6, 9,16,22],
  [10,13,14,17,24],
  [18,21,23,26,30]
]
target = 5

输出：true
```

### 约束观察

- 每行和每列分别有序，但整个矩阵不能直接视为一维有序数组。
- 右上角左侧都不大于当前值，下方都不小于当前值。
- 从右上角出发，每次比较都能排除一整行或一整列。

## 直接方案

逐个扫描全部元素，时间复杂度为 `O(mn)`。

也可以对每一行执行二分查找，时间复杂度为 `O(m log n)`。但矩阵的列有序性质还没有被充分利用。

## 优化抓手

从右上角开始。设当前位置为 `matrix[row][column]`：

- 等于 `target`：找到答案；
- 大于 `target`：当前列下方只会更大，整列可以排除，向左移动；
- 小于 `target`：当前行左侧只会更小，整行可以排除，向下移动。

移动轨迹像从右上角走向左下角的阶梯。

## Python 实现

```python
class Solution:
    def searchMatrix(
        self,
        matrix: list[list[int]],
        target: int,
    ) -> bool:
        if not matrix or not matrix[0]:
            return False

        row = 0
        column = len(matrix[0]) - 1

        # 从右上角出发：过大左移，过小下移，每步排除一行或一列。
        while row < len(matrix) and column >= 0:
            value = matrix[row][column]

            if value == target:
                return True
            if value > target:
                column -= 1
            else:
                row += 1

        return False
```

## 为什么从右上角或左下角开始

右上角同时具有两个相反方向的单调性：

```text
向左：数值不增
向下：数值不减
```

一次比较就能唯一决定移动方向。左下角同理。

如果从左上角开始，右侧和下方都更大；当前值偏小时无法判断应该向右还是向下，不能排除一整片区域。

## 排除一行或一列的依据

当前位置大于目标时，同一列下方元素都不小于当前位置，所以该列剩余部分不可能有目标值。

当前位置小于目标时，同一行左侧元素都不大于当前位置，所以该行剩余部分也不可能有目标值。

## 正确性说明

算法维护的搜索区域始终是当前行及其下方、当前列及其左侧组成的矩形。每次比较后，被删除的行或列中的所有元素都因单调性不可能等于目标，因此不会误删答案。若找到目标立即返回；若指针走出边界，搜索区域为空，说明目标不存在。

## 复杂度

- 时间复杂度：`O(m + n)`。最多向下移动 `m` 次、向左移动 `n` 次。
- 空间复杂度：`O(1)`。

## 边界用例

| 矩阵 | `target` | 预期 | 检查点 |
|---|---:|---|---|
| `[[1]]` | 1 | `True` | 单元素命中 |
| `[[1]]` | 2 | `False` | 单元素未命中 |
| `[[1,3,5]]` | 3 | `True` | 单行 |
| `[[1],[3],[5]]` | 4 | `False` | 单列 |
| `[]` | 1 | `False` | 空矩阵 |

## 90 秒面试表达

“逐元素扫描是 `O(mn)`，逐行二分是 `O(m log n)`。我从右上角开始，因为向左数值变小、向下数值变大。当前值大于目标时，当前列下方只会更大，可以整列排除并左移；当前值小于目标时，当前行左侧只会更小，可以整行排除并下移。最多移动 `m + n` 步，时间 `O(m+n)`、空间 `O(1)`。”

## 常见追问

- 从左下角出发同样可以实现阶梯搜索。
- 如果每行首元素都大于上一行末元素，矩阵可视为一维有序数组并整体二分。
- 如果要返回坐标，命中时返回 `[row, column]` 即可。
