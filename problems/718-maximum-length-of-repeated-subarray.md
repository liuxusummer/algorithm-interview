## 题目

给定两个整数数组 `nums1` 和 `nums2`，返回两个数组中公共的、长度最长的连续子数组长度。

### 示例

```text
输入：
nums1 = [1, 2, 3, 2, 1]
nums2 = [3, 2, 1, 4, 7]
输出：3
解释：最长公共连续子数组是 [3, 2, 1]
```

## 状态与转移

定义：

```text
dp[i][j] =
以 nums1[i - 1] 和 nums2[j - 1] 结尾的
最长公共连续子数组长度
```

若两个结尾元素相同，可以把此前同时结尾的公共子数组延长一位：

```text
dp[i][j] = dp[i - 1][j - 1] + 1
```

若不同，连续匹配在当前位置中断，状态必须归零。

## Python 实现

```python
class Solution:
    def findLength(
        self,
        nums1: list[int],
        nums2: list[int],
    ) -> int:
        if len(nums1) < len(nums2):
            nums1, nums2 = nums2, nums1

        dp = [0] * (len(nums2) + 1)
        maximum_length = 0

        for value1 in nums1:
            # 倒序更新，避免本行覆盖 dp[column - 1] 的上一行值。
            for column in range(len(nums2), 0, -1):
                if value1 == nums2[column - 1]:
                    dp[column] = dp[column - 1] + 1
                    maximum_length = max(
                        maximum_length,
                        dp[column],
                    )
                else:
                    dp[column] = 0

        return maximum_length
```

## 为什么一维数组必须逆序

当前状态依赖上一行的 `dp[column - 1]`。

从右向左更新时，左侧位置尚未被当前行覆盖，仍保存上一行状态；如果正序更新，就可能读取当前行刚写入的值，把同一个 `nums1` 元素重复用于连续匹配。

## 与最长公共子序列的区别

- 重复子数组要求连续：元素不同时，当前结尾状态立即归零；
- 公共子序列允许跳过元素：不同时可以继承上方或左方的最大值。

所以这题的答案可能出现在任意状态，必须额外记录全局最大值，而不一定是右下角。

## 正确性说明

当两个结尾元素相同，所有以它们结尾的公共连续子数组都由此前两个前缀的共同后缀追加当前元素得到，最长长度正好加一。元素不同时，不存在以这两个位置同时结尾的公共连续子数组，状态为零。算法枚举全部结尾组合并取最大，因此得到全局最长重复子数组长度。

## 复杂度

- 时间复杂度：`O(mn)`。
- 空间复杂度：`O(min(m, n))`，让较短数组作为列。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `[1,2,3,2,1]`, `[3,2,1,4,7]` | `3` | 基础匹配 |
| `[0,0,0]`, `[0,0]` | `2` | 重复元素 |
| `[1,2]`, `[3,4]` | `0` | 没有公共元素 |
| `[1]`, `[1]` | `1` | 单元素 |
| 相同数组 | 数组长度 | 整体匹配 |

## 90 秒面试表达

“定义状态为以两个当前位置同时结尾的最长公共连续长度。元素相同就从左上状态加一，不同则必须归零，因为题目要求连续。答案可能在任意结尾组合，所以遍历时维护最大值。一维压缩后要从右向左更新，确保读取的是上一行左上状态。时间 `O(mn)`、空间 `O(min(m,n))`。”

## 常见追问

- 若不要求连续，就变成最长公共子序列，转移方式不同。
- 也可以二分答案并用滚动哈希判断是否存在公共子数组。
- 要返回实际子数组，在更新最大长度时保存 `nums1` 中的结束位置。
