## 题目

给定长度为 `n` 的整数数组 `nums`，其中每个元素都在 `[1, n]` 范围内，每个整数最多出现两次。返回所有出现两次的整数。

要求算法时间复杂度为 `O(n)`，且除返回答案外只使用常数额外空间。

### 示例

```text
输入：[4, 3, 2, 7, 8, 2, 3, 1]
输出：[2, 3]
```

## 用值映射数组下标

值域恰好是 `[1, n]`，所以数字 `value` 可以映射到下标 `value - 1`。

这次不使用正负号，而是把数组本身当作计数器：

- 第一次看到 `value`，给 `nums[value - 1]` 加上 `n`；
- 第二次看到 `value`，对应位置已经大于 `n`，把 `value` 加入答案；
- 每次仍然给对应位置加上 `n`，持续记录出现次数。

扫描期间，当前元素可能已经被此前的数字加过 `n`。用 `(nums[i] - 1) % n` 就能消去这些增量，恢复它原本对应的下标。

## Python 实现

```python
from typing import List


class Solution:
    def findDuplicates(self, nums: List[int]) -> List[int]:
        ans = []
        n = len(nums)

        for i in range(n):
            # nums[i] 可能已被加过若干个 n；取模后恢复原值对应的下标。
            index = (nums[i] - 1) % n

            if nums[index] > n:
                # 目标位置此前已加过 n，说明 index + 1 已经出现过。
                ans.append(index + 1)

            # 直接在原数组中累计该数字的出现次数。
            nums[index] += n

        return ans
```

## 为什么取模能恢复原始值

设当前位置原本的值为 `value`，此前被当作计数槽后可能变成：

```text
value + k × n
```

因为 `value` 位于 `[1, n]`，所以：

```text
(value + k × n - 1) % n = value - 1
```

无论该位置被加过多少次 `n`，都能得到原值对应的下标。

## 为什么 `nums[index] > n` 表示重复

目标位置的原始值最多为 `n`。第一次访问下标 `index` 后，算法会执行 `nums[index] += n`，使它严格大于 `n`。

如果之后再次映射到同一个下标，说明数字 `index + 1` 已经出现过一次，此时就应加入答案。

## 正确性说明

对任意数字 `x`，只有它会访问下标 `x - 1`。第一次访问时，该位置增加 `n`；若 `x` 第二次出现，算法必然观察到目标位置已经大于 `n`，并记录 `x`。

题目保证每个值最多出现两次，因此每个重复值恰好加入答案一次；只出现一次的值在访问前不会看到目标位置大于 `n`，所以不会加入答案。取模又保证数组修改不会破坏后续元素的原始映射，最终结果恰好包含所有重复数据。

## 复杂度

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`，不计返回数组；
- 算法会修改输入数组：每个位置最终是“原值 + 对应数字出现次数 × n”。

## 边界用例

| 输入 | 输出 |
|---|---|
| `[1]` | `[]` |
| `[1, 1]` | `[1]` |
| `[1, 2, 3]` | `[]` |
| `[2, 2, 1, 1]` | `[2, 1]` |

## 90 秒面试表达

“题目的关键是值域恰好为 1 到 n，所以值 `x` 可以映射到下标 `x - 1`。我把原数组当作计数器：每看到一次 `x`，就给 `nums[x - 1]` 加 `n`；如果加之前该位置已经大于 `n`，说明 `x` 是第二次出现。由于正在读取的位置也可能被加过 `n`，用 `(nums[i] - 1) % n` 恢复原始下标。时间 `O(n)`，额外空间 `O(1)`。”

## 常见追问

- 若不能修改输入，可以使用哈希集合，但空间变为 `O(n)`；
- 若某个值可能出现三次，当前代码会从第二次开始重复加入答案；可以通过商值计算次数或增加去重判断；
- 若要求恢复数组，可在结束后执行 `nums[i] = (nums[i] - 1) % n + 1`。
