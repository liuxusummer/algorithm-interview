## 题目

给定长度为 `n` 的整数数组 `nums`，其中每个元素都在 `[1, n]` 范围内，每个整数最多出现两次。返回所有出现两次的整数。

要求算法时间复杂度为 `O(n)`，且除返回答案外只使用常数额外空间。

### 示例

```text
输入：[4, 3, 2, 7, 8, 2, 3, 1]
输出：[2, 3]
```

## 用值映射数组下标

值域恰好是 `[1, n]`，所以数字 `value` 可以映射到下标 `value - 1`。

第一次看到 `value` 时，把 `nums[value - 1]` 变成负数，表示它出现过；再次看到同一个值时，对应位置已经是负数，就把它加入答案。

扫描时数组中的符号会被修改，因此读取当前数字必须使用绝对值。

## Python 实现

```python
class Solution:
    def findDuplicates(self, nums: list[int]) -> list[int]:
        duplicates: list[int] = []

        for raw_value in nums:
            value = abs(raw_value)
            index = value - 1

            if nums[index] < 0:
                # 目标位置已经为负，说明 value 此前出现过一次。
                duplicates.append(value)
            else:
                # 利用符号记录“这个值已经出现”。
                nums[index] = -nums[index]

        return duplicates
```

## 为什么不会把修改后的负数当成新值

循环变量来自正在遍历的数组，而其中某些位置可能已被取负。`abs(raw_value)` 恢复原始值，再映射到下标，因此标记行为不会改变输入数字代表的值。

## 正确性说明

对任意数字 `x`，只有它会访问下标 `x-1`。第一次访问时，该位置由正变负；若 `x` 第二次出现，算法必然观察到负号并记录 `x`。

题目保证每个值最多出现两次，因此每个重复值恰好加入答案一次；只出现一次的值不会加入，结果正好包含所有重复数据。

## 复杂度

- 时间复杂度：`O(n)`；
- 额外空间复杂度：`O(1)`，不计返回数组；
- 算法会修改输入数组的符号。

## 边界用例

| 输入 | 输出 |
|---|---|
| `[1]` | `[]` |
| `[1, 1]` | `[1]` |
| `[1, 2, 3]` | `[]` |
| `[2, 2, 1, 1]` | `[2, 1]` |

## 90 秒面试表达

“题目的关键是值域恰好为 1 到 n，所以值 `x` 可以映射到下标 `x-1`。第一次看到 `x` 时把对应位置取负，第二次看到时该位置已经为负，就说明 `x` 重复。由于数组会被修改，读取当前值时要取绝对值。时间 `O(n)`，额外空间 `O(1)`。”

## 常见追问

- 若不能修改输入，可以使用哈希集合，但空间变为 `O(n)`；
- 若某个值可能出现三次，需要额外处理，当前符号只能表达“是否见过”；
- 若要求恢复数组，结束后再把所有元素取绝对值。
