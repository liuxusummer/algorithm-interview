## 题目

有 `n` 封不同的信，以及分别写着这 `n` 位收件人名字的 `n` 个信封。

现在要把每封信恰好装入一个信封，并且没有任何一封信装入写着自己收件人名字的信封。请返回一共有多少种不同的装法。

换一种说法：求 `1...n` 的排列中，满足每个位置 `i` 都有 `permutation[i] != i` 的排列数量。

### 数据范围

- `0 <= n <= 1000`；
- 返回精确整数，不取模；
- 约定空集合有 1 个空排列，所以 `D(0) = 1`。

## 示例

### 示例 1

```text
输入：n = 2
输出：1
```

只有一种错排：

```text
[2, 1]
```

### 示例 2

```text
输入：n = 3
输出：2
```

两种错排：

```text
[2, 3, 1]
[3, 1, 2]
```

### 示例 3

```text
输入：n = 4
输出：9
```

## 从第一封信推导递推式

记 `D(n)` 为 `n` 个元素的错排数量。

观察编号为 1 的信。它不能放进 1 号信封，因此可以选择其余 `n - 1` 个信封。假设它放进了编号为 `j` 的信封，接下来分两种情况。

### 情况 1：j 号信放进 1 号信封

信 1 和信 `j` 形成一个二元交换。去掉这两封信和两个信封后，剩余 `n - 2` 个元素仍必须全部错排，方案数为：

```text
D(n - 2)
```

### 情况 2：j 号信不放进 1 号信封

可以把 1 号信封看作 `j` 号信在剩余问题中不能选择的那个“原位”。经过重新编号后，剩下 `n - 1` 封信仍构成一个错排问题，方案数为：

```text
D(n - 1)
```

信 1 的目标信封 `j` 有 `n - 1` 种选择，因此得到递推式：

```text
D(n) = (n - 1) × (D(n - 1) + D(n - 2))
```

初始值为：

```text
D(0) = 1
D(1) = 0
```

## Python 实现

```python
class Solution:
    def countDerangements(self, n: int) -> int:
        if n < 0:
            raise ValueError("n 不能为负数")
        if n == 0:
            return 1
        if n == 1:
            return 0

        two_steps_back = 1  # D(0)
        one_step_back = 0   # D(1)

        for size in range(2, n + 1):
            # 固定 1 号元素的去向后，分成“互换”和“不互换”两类。
            current = (size - 1) * (
                one_step_back + two_steps_back
            )
            two_steps_back, one_step_back = (
                one_step_back,
                current,
            )

        return one_step_back
```

## 正确性说明

所有合法错排都能按“1 号信进入哪个信封”进行唯一分类，共有 `n - 1` 个候选信封。

固定候选信封 `j` 后：

- 如果 `j` 号信进入 1 号信封，剩余部分与一个大小为 `n - 2` 的错排一一对应；
- 如果 `j` 号信不进入 1 号信封，剩余部分与一个大小为 `n - 1` 的错排一一对应。

两类情况互斥且覆盖全部合法方案，因此每个 `j` 对应 `D(n - 2) + D(n - 1)` 种方案。再乘以 `n - 1` 个 `j`，递推式正确。

代码从正确的初始值 `D(0)`、`D(1)` 出发，按递推式依次计算到 `D(n)`，所以返回值就是题目要求的错排数量。

## 复杂度

- 从 2 到 `n` 线性递推，时间复杂度为 `O(n)`；
- 只保存前两个状态，除返回的大整数外，额外空间复杂度为 `O(1)`。

> Python 整数会自动扩容。若把大整数的位数成本也计算在内，乘法和加法并非严格常数时间；面试中通常按动态规划状态数报告 `O(n)`。

## 另一个公式

利用容斥原理还可以得到：

```text
D(n) = n! × Σ((-1)^i / i!)，其中 0 <= i <= n
```

并且：

```text
D(n) = round(n! / e)
```

递推写法更适合编程面试，因为它只依赖整数运算，不会引入浮点精度问题，也容易说明状态来源。

## 60～90 秒口述稿

我用 `D(n)` 表示 `n` 个元素的错排数。先看 1 号元素，它有 `n - 1` 个非原位可以选，假设放到 `j` 的位置。

如果 `j` 又放回 1 的位置，那么这两个元素形成交换，剩下是 `D(n - 2)`；如果 `j` 不放回 1 的位置，重新编号后剩下是 `D(n - 1)`。所以递推式是 `D(n) = (n - 1) × (D(n - 1) + D(n - 2))`。

初始值 `D(0) = 1`、`D(1) = 0`。代码只滚动保存前两个状态，时间 `O(n)`，额外空间 `O(1)`。Python 可以直接返回精确大整数，不需要取模。

## 常见追问

### 1. 为什么 D(0) 等于 1？

空集合有一个空排列，而且它没有任何元素处于错误位置之外，因此组合数学中约定 `D(0) = 1`。这个初始值也能让 `D(2)` 的递推自然成立。

### 2. 如果题目要求对 1_000_000_007 取模呢？

每次计算 `current` 后立即取模即可，递推关系不变：

```python
current = (size - 1) * (
    one_step_back + two_steps_back
) % 1_000_000_007
```

### 3. 为什么不直接使用 round(n! / e)？

公式适合数学估算，但大规模阶乘转浮点数会溢出或丢失精度。递推只做整数运算，能够得到精确答案。
