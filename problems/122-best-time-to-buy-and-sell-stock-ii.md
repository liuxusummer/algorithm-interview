## 题目

给定每天的股票价格，可以完成任意多笔交易，但同一时间最多持有一股股票：再次买入前必须先卖出。

返回能够获得的最大利润。

### 示例

```text
输入：prices = [7, 1, 5, 3, 6, 4]
输出：7
解释：1 买 5 卖获利 4，3 买 6 卖获利 3
```

```text
输入：prices = [1, 2, 3, 4, 5]
输出：4
```

## 贪心选择

只要明天价格高于今天，就获取这段相邻上涨收益：

```text
profit += prices[i] - prices[i - 1]
```

连续上涨 `1 → 3 → 5` 时，分成两次相邻交易的利润为：

```text
(3 - 1) + (5 - 3) = 5 - 1
```

它与谷底买入、峰顶卖出的利润完全相同，因此可以把所有上涨区间拆成相邻正收益。

## Python 实现

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        total_profit = 0

        # 每段正向涨幅都可独立兑现，累加等价于抓住整段上涨。
        for previous, current in zip(prices, prices[1:]):
            if current > previous:
                total_profit += current - previous

        return total_profit
```

## 为什么不会违反持仓约束

把连续上涨拆成“今天买、明天卖”的多笔交易时，相邻两笔可能表现为同一天卖出后又买入。它等价于一直持有，利润不变，也没有同时持有多股。

下跌段不产生正收益，应在下跌前卖出、下跌后再买入。

## 正确性说明

任意一笔从第 `a` 天买入、第 `b` 天卖出的利润都能写成区间内相邻价差之和。负价差只会降低利润，而所有正价差都可以通过合法的连续交易获得。因此舍弃所有非正价差、累加全部正价差，既构造出可行策略，也达到任何策略无法超过的上界，所以结果最优。

## 复杂度

- 时间复杂度：`O(n)`，只扫描一次相邻价格。
- 空间复杂度：`O(1)`。

## 边界用例

| 输入 | 预期 | 检查点 |
|---|---:|---|
| `[7,1,5,3,6,4]` | `7` | 多段上涨 |
| `[1,2,3,4,5]` | `4` | 连续上涨 |
| `[7,6,4,3,1]` | `0` | 持续下跌 |
| `[1]` | `0` | 无法交易 |
| `[1,1,2]` | `1` | 相同价格 |

## 90 秒面试表达

“允许无限次交易且没有手续费时，任意一段上涨利润都可以拆成相邻正价差之和。例如 `1→3→5` 的利润等于 `(3-1)+(5-3)`。所以遍历所有相邻天，只要今天比昨天贵，就把价差加入答案；下跌价差直接跳过。这个策略可以通过当天卖出再买入等价为持续持有，不违反持仓约束。时间 `O(n)`、空间 `O(1)`。”

## 常见追问

- 有手续费时，不能简单累加每段正收益，需要状态 DP 或调整有效买入成本。
- 有冷冻期时，状态要区分持有、刚卖出和可买入。
- 只允许一笔交易时，回到第 121 题维护历史最低价。
