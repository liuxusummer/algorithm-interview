## 题目

数组中每个元素表示从该位置最多可以向右跳多少步。判断能否从下标 `0` 到达最后一个下标。

### 示例

```text
输入：nums = [2, 3, 1, 1, 4]
输出：true
解释：从下标 0 跳到 1，再从下标 1 到达末尾。
```

```text
输入：nums = [3, 2, 1, 0, 4]
输出：false
解释：无论怎样跳，都会被下标 3 的零阻断。
```

### 约束观察

- `nums[i]` 表示“最多”可跳距离，可以选择更短的步长；
- 题目只问是否可达，不要求具体路径或最少跳跃次数；
- 只要某个可达位置把最远边界扩展到末尾，就可以提前返回。

## 先说动态规划

可以令 `reachable[i]` 表示下标 `i` 是否可达，再从所有前驱位置转移，最坏时间为 `O(n²)`。其实我们不关心每个位置由谁到达，只关心当前所有可达位置能覆盖到的最远边界。

## 贪心思路

从左到右维护当前能够到达的最远位置。若遍历到的下标超过最远位置，说明中间出现了无法跨越的断点；否则用当前位置继续扩展最远边界。

## Python 实现

```python
from typing import List


class Solution:
    def canJump(self, nums: List[int]) -> bool:
        farthest = 0

        for index, step in enumerate(nums):
            if index > farthest:
                return False

            # 只关心所有可达位置能扩展出的最远边界
            farthest = max(farthest, index + step)
            if farthest >= len(nums) - 1:
                return True

        return True
```

## 正确性说明

遍历到 `index` 时，`farthest` 是此前所有可达位置能够到达的最远下标。若 `index > farthest`，该位置及其右侧都无法到达；否则将其跳跃能力纳入边界。边界覆盖末尾时即证明存在可行路径。

### 边界扩展过程

以 `[2, 3, 1, 1, 4]` 为例：

| 下标 | 步长 | 更新前最远位置 | 更新后 |
|---:|---:|---:|---:|
| `0` | `2` | `0` | `2` |
| `1` | `3` | `2` | `4` |

此时已经覆盖末尾，不必继续遍历。

## 复杂度

- 时间：`O(n)`
- 空间：`O(1)`

## 边界用例

| 输入 | 输出 | 检查点 |
|---|---|---|
| `[0]` | `True` | 起点就是终点 |
| `[0, 1]` | `False` | 起点无法移动 |
| `[2, 0, 0]` | `True` | 可以直接跨到末尾 |
| `[1, 1, 0, 1]` | `False` | 中途出现不可跨越断点 |

## 90 秒面试表达

动态规划会记录所有位置的可达性，但本题只关心最远覆盖范围。我从左到右维护 `farthest`：如果当前下标已经超过它，说明这里不可达，直接返回失败；否则用 `index + nums[index]` 扩展边界。边界覆盖末尾就成功。每个位置最多访问一次，时间 `O(n)`、空间 `O(1)`。

## 常见追问

- 本题问“能否到达”，不需要计算具体跳法；
- 如果问最少跳跃次数，需要在可达区间内分层更新下一层最远边界；
- 更新边界前必须先确认当前下标可达。
