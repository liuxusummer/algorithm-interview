# 题解内容规范

## 写作目标

每篇题解必须同时回答三个问题：

1. 为什么想到这个方案？
2. 为什么这个方案正确？
3. 面试时怎样把它讲清楚？

## 固定结构

1. 题意与约束；
2. 暴力方案及瓶颈；
3. 优化抓手和不变量；
4. 可运行代码；
5. 正确性说明；
6. 时间与空间复杂度；
7. 边界用例；
8. 60～90 秒口述稿；
9. 常见追问与变式。

## 代码标准

- 所有算法实现统一使用 Python 3；TypeScript 只用于网站主题与组件。
- 力扣题优先采用可直接提交的 `class Solution` 方法签名。
- Python 代码遵循 PEP 8，变量名表达算法含义。
- 变量名表达含义，避免无上下文的单字母缩写。
- 明确空输入、重复值、负数、溢出和下标边界。
- 代码必须与文字描述同一方案。
- 不只写“时间复杂度为 O(n)”，还要说明哪个操作执行了多少次。

## 内容边界

- 不把记住某段代码描述成掌握某类题。
- 不虚构题目频率、公司标签或面试数据。
- 属于力扣的题目必须附上对应的 `leetcode.cn` 原题链接；非力扣题不显示力扣入口。
- 引用题目原文、官方题解或外部资料时记录来源。
